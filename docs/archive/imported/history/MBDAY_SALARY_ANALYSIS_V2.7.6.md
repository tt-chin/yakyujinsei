# 野球之旅 v2.7.6 球員薪資計算解析

> 解析網站：https://mbday.myz.tw/  
> 線上版本：v2.7.6  
> 確認日期：2026-08-30  
> 內部金額單位：萬台幣

---

## 1. 資料目的

本資料整理「野球之旅 My Baseball Days」v2.7.6的球員薪資、合約、自由市場與薪資仲裁計算方式，供下列用途確認：

- 確認球員年薪如何由能力與實際成績產生。
- 判斷年薪增加、維持或減少的原因。
- 區分市場評價、固定年薪、簽約金、保障金額與激勵獎金。
- 確認守位、傷病、長短約、球團信任與服務年資的影響。
- 找出程式內可能未完整接上的薪資邏輯。

本資料以網站公開的JavaScript原始碼為準，不以畫面文字反推公式，也不包含其他網站或舊版本比較。

---

## 2. 薪資計算總流程

```text
球員能力
  ↓
當季基礎表現 d
  ↓
實際 ERA／WHIP 或 OPS／AVG
  ↓
有效出賽樣本判定
  ↓
生涯獎項加成
  ↓
市場評價 score
  ↓
聯盟基礎年薪 salaryFor
  ↓
自由市場／長短約／仲裁等合約係數
  ↓
野手守位係數
  ↓
簽約時鎖定固定年薪 annual
  ↓
季末依傷病保障決定實領年薪
  ↓
符合條件時追加激勵獎金
```

### 2.1 核心結論

```text
年度年薪 = 聯盟基礎薪資 × 合約係數 × 守位係數
```

聯盟基礎薪資使用的是當季市場評價 `marketForm.score`，不是直接使用畫面上的綜合能力。

這套制度不使用最近三季加權，主要看當季實際成績；過去生涯獎項只提供有限的小幅加成。

## 3. 當季基礎表現 d

### 3.1 投手

```text
d =（球速 + 控球 + 球威）÷ 3
  − 所屬層級平均值 par
  + 當季臨場加成
```

體力不直接加入 `d`，但會影響：

- 先發或後援定位。
- 出賽場次。
- 投球局數。
- 是否達到有效樣本。
- 最終市場評價。

#### 計算例

```text
日職一軍投手
球速60、控球57、球威58
日職一軍 par = 53

d =（60 + 57 + 58）÷ 3 − 53
  = 5.33
```

### 3.2 野手

```text
d = 打擊 × 0.60
  + 選球 × 0.20
  + 速度 × 0.20
  − 所屬層級平均值 par
  + 當季臨場加成
```

| 能力 | 是否直接計入d | 說明 |
|---|---:|---|
| 打擊／Contact | 60% | 最主要項目 |
| 選球／Eye | 20% | 直接計入 |
| 速度／Speed | 20% | 直接計入 |
| 長打／Power | 否 | 透過全壘打、長打率與OPS間接影響市場評價 |
| 體力 | 否 | 影響出賽數及打席 |
| 守備 | 否 | 年薪階段另外套用守位係數 |

### 3.3 各層級平均值

| 代碼 | 層級 | par | 最低能力 | 球季場次 |
|---|---|---:|---:|---:|
| CPBL2 | 中職二軍 | 34 | 30 | 80 |
| CPBL1 | 中職一軍 | 44 | 41 | 120 |
| NPB2 | 日職二軍 | 47 | 44 | 100 |
| NPB1 | 日職一軍 | 53 | 50 | 143 |
| R | 新人聯盟 | 41 | 39 | 55 |
| A1 | 1A | 45 | 43 | 110 |
| A2 | 2A | 49 | 47 | 120 |
| A3 | 3A | 54 | 52 | 130 |
| MLB | 大聯盟 | 59 | 56 | 162 |
| INDY_US | 北美獨立聯盟 | 48 | 40 | 126 |
| INDY_JP | 日本獨立聯盟 | 45 | 37 | 55 |
| AMATEUR_A | 台灣社會甲組 | 40 | 30 | 40 |

## 4. 市場評價 marketForm.score

球員談新約時不直接使用原始 `d`，而是使用：

```text
基礎d
+ 當季帳面成績
+ 有效出賽樣本
+ 生涯獎項加成
```

一般健康球季的市場評價最後限制在：

```text
−6 ～ +7
```

### 4.1 投手市場評價

```text
score = 基礎d × 0.35
      + ERA修正
      + WHIP修正
      + 樣本修正
      + 生涯獎項加成
```

#### ERA修正

| ERA | 修正 |
|---:|---:|
| ≤ 2.90 | +2.50 |
| ≤ 3.50 | +1.40 |
| ≤ 4.10 | +0.40 |
| ≤ 4.80 | −0.70 |
| ≤ 5.60 | −1.80 |
| > 5.60 | −3.00 |

#### WHIP修正

| WHIP | 修正 |
|---:|---:|
| ≤ 1.12 | +1.30 |
| ≤ 1.28 | +0.55 |
| ≤ 1.42 | −0.35 |
| ≤ 1.58 | −1.10 |
| > 1.58 | −1.80 |

#### 有效樣本

| 投手類型 | 頂級聯盟 | 非頂級聯盟 |
|---|---:|---:|
| 先發投手 | 70局 | 32局 |
| 後援投手 | 25局 | 16局 |

```text
達到有效樣本：+0.4
未達有效樣本：−1.5
```

### 4.2 野手市場評價

```text
score = 基礎d × 0.35
      + OPS修正
      + AVG修正
      + 樣本修正
      + 生涯獎項加成
```

#### OPS修正

| OPS | 修正 |
|---:|---:|
| ≥ .900 | +2.50 |
| ≥ .800 | +1.40 |
| ≥ .720 | +0.40 |
| ≥ .650 | −0.70 |
| ≥ .570 | −1.80 |
| < .570 | −3.00 |

#### 打擊率修正

| AVG | 修正 |
|---:|---:|
| ≥ .310 | +1.00 |
| ≥ .275 | +0.35 |
| ≥ .240 | −0.45 |
| < .240 | −1.10 |

#### 有效樣本

| 層級 | 最低打席 |
|---|---:|
| 頂級聯盟 | 250打席 |
| 非頂級聯盟 | 130打席 |

```text
達到有效樣本：+0.4
未達有效樣本：−1.5
```

### 4.3 試算例

假設一名MLB野手：

```text
基礎d = 8
OPS = .850
AVG = .285
打席 = 500
生涯獎項加成 = 0.8

基礎能力：8 × 0.35 = 2.80
OPS修正：            +1.40
AVG修正：            +0.35
有效樣本：           +0.40
獎項加成：           +0.80
────────────────────────
市場評價：            5.75
```

薪資公式使用的是 `5.75`，不是原始 `d=8`。

## 5. 生涯獎項加成

```text
市場獎項加成 = careerAwardScore × 0.2
```

最高限制：

```text
+1.8
```

| 獎項類型 | 每次權重 |
|---|---:|
| 年度MVP | 1.00 |
| 賽揚獎 | 1.00 |
| 澤村賞 | 1.00 |
| 投手三冠王 | 1.00 |
| 打擊三冠王 | 1.00 |
| 一般王座／守備獎／新人王 | 0.40 |
| 明星賽相關 | 0.15 |

同一種獎項最多只計6次。

#### 試算例

```text
MVP 3次：       3 × 1.00 = 3.0
全壘打王4次：  4 × 0.40 = 1.6
明星賽6次：    6 × 0.15 = 0.9

獎項總分 = 5.5
市場加成 = 5.5 × 0.2 = +1.1
```

## 6. 傷缺球季的市場評價

若沒有有效球季資料，或：

```text
seasonFactor < 0.5
```

市場評價直接改為：

```text
score = min（原始d，−2）
```

因此即使球員能力很高，重大傷勢或有效出賽不足時，市場也只會以 `−2` 或更低評價開價。

負評價帶入頂級聯盟薪資公式時會被夾成0，但仍會透過下列方式降低實際待遇：

- 只能簽短約。
- 長短約基礎係數降為0.8。
- 自由市場報價係數下降。
- 報價隊數減少。
- 增加完全無人報價的可能。

## 9. 野手守位係數

野手年薪在簽約時另外乘守位係數：

| 守位 | 薪資係數 |
|---|---:|
| 游擊 SS | ×1.15 |
| 中外野 CF | ×1.15 |
| 捕手 C | ×1.12 |
| 二壘 2B | ×1.05 |
| 三壘 3B | ×1.05 |
| 右外野 RF | ×1.05 |
| 一壘 1B | ×1.00 |
| 左外野 LF | ×1.00 |
| 指定打擊 DH | ×0.92 |
| 投手 | ×1.00 |

#### 試算例

市場基礎年薪1,000萬：

```text
游擊手：1,000 × 1.15 = 1,150萬
捕手：  1,000 × 1.12 = 1,120萬
一壘手：1,000 × 1.00 = 1,000萬
DH：    1,000 × 0.92 =   920萬
```

守位係數在簽約當下鎖定，不會因之後移防而追溯修改現行合約。

## 10. 長約與短約係數

### 10.1 市場評價基礎係數

| 市場評價 | 基礎係數 |
|---:|---:|
| d ≥ 3 | ×1.20 |
| 0 ≤ d < 3 | ×1.00 |
| d < 0 | ×0.80 |

### 10.2 長短約調整

```text
長約 = 基礎係數 × 0.92
短約 = 基礎係數 × 1.12
```

| 市場評價 | 長約係數 | 短約係數 |
|---:|---:|---:|
| d ≥ 3 | ×1.104 | ×1.344 |
| 0～2.99 | ×0.920 | ×1.120 |
| d < 0 | ×0.736 | ×0.896 |

- 長約年薪較低，但保障年限較長。
- 短約年薪較高，賭下一次市場。
- 市場評價低於0時通常只能拿短約。

### 10.3 神主牌

神主牌球員與目前效力的母隊談約時：

```text
基礎係數最低為 ×1.20
```

這項忠誠紅利只屬於母隊，不會跟著球員帶到其他球隊。

## 11. 自由市場報價

### 11.1 球隊報價係數

```text
報價係數 = clamp（0.72 + d×0.06 + 隨機0～0.10，0.62，1.55）
```

這個係數再乘長約或短約係數。

#### 試算例

市場評價 `d=5`：

```text
球隊報價係數：
0.72 + 5×0.06 + 0～0.10
= 1.02～1.12

高評價短約係數：
1.20 × 1.12 = 1.344

合成係數：
1.02～1.12 × 1.344
= 約1.37～1.51
```

野手再乘守位係數。

### 11.2 報價隊數

| 市場評價 | 基本報價數 |
|---:|---|
| d ≥ 3 | 2～4隊 |
| d ≥ 1 | 1～3隊 |
| d ≥ −1 | 1～2隊 |
| d ≥ −3 | 1隊 |
| d < −3 | 30%機率1隊，否則無報價 |

「更衣室毒瘤」會使報價數再減少1隊。

### 11.3 完全無人報價

可以回原隊簽1年減薪約：

```text
年薪係數 ×0.70
```

例如基礎年薪1,000萬的游擊手：

```text
1,000 × 0.70 × 1.15 = 805萬
```

也可以選擇引退。

### 11.4 有其他球隊報價時的母隊留人

母隊不再固定用低價留人，而是參考市場最佳報價：

```text
母隊係數下限：0.95
母隊係數上限：1.55
```

球團信任最高可影響約±6%，神主牌再加6%。

## 12. 控制期續約與薪資仲裁

### 12.1 球團開價係數

```text
球團係數 = 0.91
          + 市場評價×0.045
          +（球團信任−50）×0.002
          + min（服務年資，6）×0.045
```

限制：

```text
0.80～1.45
```

### 12.2 球員主張係數

```text
球員係數 = 球團係數
          + 0.08
          + max（0，市場評價）×0.018
```

限制：

```text
0.92～1.70
```

### 12.3 折衷係數

```text
折衷係數 =（球團係數 + 球員係數）÷ 2
```

### 12.4 仲裁勝率

```text
勝率 = 47
     + 市場評價×8
     + min（服務年資，6）×2
```

限制：

```text
15%～88%
```

球團信任影響回談成功率與開價，但不影響第三方仲裁庭的勝率。

### 12.5 仲裁結果

勝訴：

```text
係數 = max（球員主張係數，1.15～1.40的隨機值）
```

敗訴：

```text
係數 = min（球團係數，0.90）
```

### 12.6 單季最大強制減薪

控制期續約或仲裁結果具有保護：

```text
新年薪不得低於去年年薪的75%
```

也就是單季最多強制減薪25%。

此保護不套用：

- FA自由市場。
- 玩家自行選擇的長約。
- 延長續約。
- 無人報價後回原隊。

## 15. 合約年限

### 15.1 類型上限

| 球員類型 | 最長合約 |
|---|---:|
| 野手 | 9年 |
| 投手 | 7年 |

### 15.2 年限公式

```text
表現係數 = clamp（（d + 2）÷ 8，0，1）

年限 = round（2
      + 表現係數×（類型上限−2）
      − 傷病歷史懲罰）
```

傷病歷史懲罰：

```text
每次重大傷勢：0.12 × 類型上限
每次TJ手術：  0.15 × 類型上限
```

### 15.3 年齡上限

| 年齡 | 最長合約 |
|---|---:|
| 27歲以下 | 類型原上限 |
| 28～29歲 | 8年 |
| 30～31歲 | 6年 |
| 32～33歲 | 5年 |
| 34～35歲 | 3年 |
| 36歲以上 | 2年 |

市場評價低於0或最長年限不超過2年時，不提供長約。

## 16. 固定合約與延長續約

簽約時會保存：

```text
固定年薪 annual
合約年限 yrs
保障總額 guaranteed
激勵獎金 incentive
傷病保障 injuryProtected
守位係數
合約分段 segments
```

合約有效期間內：

- 好成績不會直接加薪。
- 差成績不會直接減薪。
- 被交易後合約條件原封不動。
- 被下放不會自動重算現行年薪。
- 守位改變不會追溯修改現行合約。

### 16.1 延長續約

提前延長時：

- 原合約最後一年照原條件履行。
- 新合約接在舊合約後面。
- 新年薪不會覆蓋舊約剩餘年度。
- 合計保障金額依每一合約分段加總。

## 17. 傷病球季實際領薪

### 17.1 三年以上合約

```text
injuryProtected = true
```

全年報銷仍領完整固定年薪。

### 17.2 一至二年短約

```text
injuryProtected = false
```

全年報銷時：

```text
實領年薪 = 固定年薪 × 50%
```

因此長約不只是保障未來年限，也包含全年傷病時的完整年薪保障。

## 18. 激勵獎金

合約另有年度激勵上限：

| 組織 | 激勵上限 |
|---|---:|
| 美職體系 | 年薪的10% |
| 其他聯盟 | 年薪的7% |

### 18.1 全額激勵

當年度取得指定獎項，例如：

- MVP。
- 各項王座。
- 賽揚獎。
- 澤村賞。
- 最佳投手。
- 金手套。

即可取得完整激勵獎金。

### 18.2 半額激勵

沒有指定獎項，但：

```text
lastD ≥ 3
```

可取得激勵上限的50%。

重大傷缺或有效出賽不足時沒有激勵獎金。

## 21. 二刀流市場評價

二刀流先依投打工作量合併原始 `d`：

```text
投球權重 = max（0.15，投球負荷×0.60）
打擊權重 = max（0.15，打擊負荷×0.40）

綜合d =（投球d×投球權重 + 打擊d×打擊權重）
       ÷（投球權重 + 打擊權重）
```

另有明星表現保護：

```text
投滿50局：綜合d至少保留投球d的88%
打滿150打席：綜合d至少保留打擊d的88%
```

避免其中一條路線樣本較少時，把另一條明星級表現完全拉低。

## 22. 程式邏輯確認結果

### 22.1 市場評價上限與薪資曲線上限不一致

聯盟薪資曲線允許：

```text
中職：d最高25
日職：d最高26
MLB： d最高26
```

但是一般續約與FA使用的：

```text
marketForm.score最高只有7
```

因此常規市場的基礎年薪通常最多為：

| 聯盟 | d=7基礎年薪 |
|---|---:|
| 中職一軍 | 1,280萬 |
| 日職一軍 | 2,565萬台幣 |
| MLB | 3億7,400萬台幣 |

`d=8～26`的薪資曲線主要只能在直接使用原始 `lastD` 的流程，或透過後續倍率間接接近。這不一定是程式錯誤，但兩套上限的設計意圖不完全一致。

### 22.2 母隊FA續約的傷病短約加成未實際套用

程式先計算：

```text
傷病史至少2次，且只能拿3年以下短約時：母隊係數+0.15
```

但進入母隊長短約選單時，這個計算結果沒有傳給 `termChoice()`，因此對直接與母隊FA續約沒有作用。

其他自由市場球隊的報價有正確加入 `+0.15`。

### 22.3 同聯盟FA報價會覆蓋球隊需求係數

產生球隊報價時，最初建立：

```text
球隊需求係數 = 1 + 球隊需求×0.025
```

但同聯盟FA流程後續又直接改寫 `of.mult`：

```text
of.mult = clamp（0.72 + d×0.06 + 隨機值，0.62，1.55）
```

因此原先的球隊需求加價沒有保留在同聯盟FA年薪中。

實際結果：

- 球隊需求仍可能影響球隊選擇與簽約金。
- 但同聯盟FA年薪不一定保留球隊需求溢價。

## 23. 薪資異常確認順序

玩家反映薪資不合理時，建議依序確認：

1. 確認球員是否仍在固定多年約。
2. 確認當季原始 `lastD`。
3. 確認實際 `marketForm.score`。
4. 確認投手ERA、WHIP或野手OPS、AVG修正。
5. 確認局數或打席是否達到有效樣本。
6. 確認是否為重大傷勢或整季報銷。
7. 確認生涯獎項加成是否已達1.8上限。
8. 確認使用的是長約、短約、FA報價或控制期係數。
9. 確認野手簽約時的守位係數。
10. 確認是否為神主牌母隊續約。
11. 確認球團信任與服務年資對控制期開價的影響。
12. 確認是否經過薪資仲裁。
13. 確認75%減薪保護是否適用。
14. 確認全年報銷時合約是否有三年以上傷病保障。
15. 確認畫面顯示的是固定年薪、保障總額、簽約金、激勵獎金或生涯薪資。
16. 確認日圓／美元只是在顯示層換算。

## 24. 核心公式速查

```text
【投手基礎d】
d =（球速 + 控球 + 球威）÷3 − par + 臨場加成

【野手基礎d】
d = 打擊×0.60 + 選球×0.20 + 速度×0.20 − par + 臨場加成

【投手市場評價】
score = d×0.35 + ERA修正 + WHIP修正 + 樣本修正 + 獎項加成

【野手市場評價】
score = d×0.35 + OPS修正 + AVG修正 + 樣本修正 + 獎項加成

【中職一軍】
salary = 300 + clamp（d，0，25）×140

【日職一軍】
salary = 325 + clamp（d，0，26）×320

【MLB】
salary = 2,400 + clamp（d，0，26）×5,000

【合約年薪】
annual = round（salaryFor × 合約係數 × 守位係數）

【長短約】
長約係數 = 市場基礎係數×0.92
短約係數 = 市場基礎係數×1.12

【自由市場報價】
offerMult = clamp（0.72 + d×0.06 + 隨機0～0.10，0.62，1.55）

【傷病實領】
三年以上保障約全年報銷：固定年薪100%
一至二年短約全年報銷：固定年薪50%
```

## 26. 最終結論

野球之旅v2.7.6的薪資核心為：

```text
聯盟基礎年薪
× 市場合約係數
× 野手守位係數
```

市場評價主要由當季實際表現產生：

```text
投手：基礎d×35% + ERA + WHIP + 樣本 + 生涯獎項
野手：基礎d×35% + OPS + AVG + 樣本 + 生涯獎項
```

合約簽下後會變成固定年薪；之後的好壞成績主要影響下一份合約，不會自動改變目前合約。長約除了年限保障，也能在全年報銷時保留完整薪資；短約年薪較高，但若沒有傷病保障，整季報銷只領50%。
