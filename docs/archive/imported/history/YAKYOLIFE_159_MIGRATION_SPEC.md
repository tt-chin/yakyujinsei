## 3. 調査で確認したYaKyoLifeの特徴

### 3.1 開始画面

- 選手名と背番号を同じ行で入力
- 投手、捕手、内野手、外野手を選択
- seedを直接入力または再生成
- 表示設定をゲーム開始前に変更
- 現在バージョンを表示
- ゲームの流れを一文で説明

### 3.2 表示設定

4種類のテーマを提供している。

```text
深緑スコアボード
電光掲示板
新聞紙面
モダンダッシュボード
```

さらに次を選択できる。

```text
標準文字／大きい文字
PCレイアウト／モバイルレイアウト
```

端末幅だけで自動判定せず、ユーザーが任意にPC版またはモバイル版を選べる点が特徴である。

### 3.3 ゲーム内情報

ヘッダーには次を表示する。

- 背番号
- 選手名
- 役割
- 所属と所属階層
- 年齢
- 年度
- 総合
- 生涯収入
- シーズン前／中／終了の進行状態

詳細パネルは次の4タブで構成される。

```text
実績
契約・収入
特性
年度別
```

### 3.4 育成

- 複数のダイス結果を先に表示
- ダイスを能力へ割り当てる
- 現在能力と潜在上限を`現在値 / 上限`で表示
- 成長効率が低下する境界を説明
- 今回の割当を元に戻せる

### 3.5 キャリア記録

- 年度別成績
- 受賞歴
- 現行契約
- 球団在籍年数
- 生涯収入
- 隠し特性
- 国際大会の大会別成績
- 引退後の評価と結末

## 5. 背番号システム

### 5.1 目的

選手の識別性を高め、試合記録、共有画像、引退演出、永久欠番に一貫して使用する。

### 5.2 入力仕様

- 入力範囲：`0`～`99`
- 未入力の場合は守位別の候補から決定
- 先頭ゼロは保存時に正規化する
- 数字以外を受け付けない
- ブラウザ自動補完を無効化する
- 選手名と背番号を同じ行へ配置する
- 2桁でも切れない幅を確保する

### 5.3 日本向け候補

守位ごとの初期候補は日本野球で自然な傾向を参考にするが、実在選手の再現に固定しない。

| 守位 | 候補例 |
| --- | --- |
| 投手 | 11、17、18、19、21 |
| 捕手 | 2、22、27、39 |
| 内野手 | 3、5、6、7、23 |
| 外野手 | 1、8、9、51、55 |

### 5.4 表示場所

- 開始画面
- ゲーム内ヘッダー
- 選手詳細
- 年度別記録
- 契約・移籍カードで必要な場合
- 引退画面
- 引退共有画像
- 永久欠番／背番号継承イベント

通常イベント本文では毎回名前に背番号を付けず、選手名のみを基本とする。

### 5.5 永久欠番候補

永久欠番は単に高評価だから自動発生させず、次を組み合わせる。

- 同一球団でのトップリーグ在籍年数
- 同一球団での総在籍年数
- 球団での主要受賞
- 球団優勝への貢献
- 移籍の有無
- 引退時の代表球団

既存の「○○一筋」条件と重複・競合しないよう、永久欠番条件は別途仕様化する。

### 5.6 テスト

- `0`、`1`、`9`、`10`、`18`、`99`
- 空欄
- 全角数字
- 3桁以上
- 文字混入
- PC、モバイル、共有画像で2桁が切れない

- 現在有効な特性
- 永久称号

- 解放年
- 発動条件の概要

## 8. 育成ダイス割当の改善

### 8.1 表示

```text
球速　38 / 49
制球　21 / 59
変化球　30 / 78
体力　23 / 67
```

- 現在値と潜在上限を同時表示
- 未使用ダイスを一覧表示
- 適用済みダイスを視覚的に区別
- 今回の割当を一括して元に戻す
- 上限到達時は選択不能にする

### 8.2 成長コスト説明

能力帯によって成長効率が変わる場合、画面表示と実際の計算を同じ関数から取得する。

例：

```text
60以上：成長効率低下
70以上：さらに低下
潜在上限超過：特別条件時のみ
```

固定説明文へ数値を二重記載しない。

### 8.3 投手の体力コスト

体力は先発適性に必要だが、球速・制球・変化球と同じ高コスト曲線にすると先発だけが過度に不利になる可能性がある。

日本語版で変更する場合は次を比較する。

- 現行`1.0.3`の能力分布
- 先発、救援、中継ぎの到達能力
- 潜在上限への到達率
- 名人堂率
- 年俸分布
- TJ発生率

これはバランス変更であり、UI改善と同時に実装しない。

## 9. 契約制度と市場評価

## 9.1 契約カード

契約前に次を表示する。

```text
球団
リーグ／階層
現在年俸
提示年俸
前年比
契約年数
保障総額
契約種別
想定役割
提示理由
契約開始年度
```

ポスティングの場合：

```text
球員の保障総額
母球団への譲渡金
譲渡金は選手収入に含まれないこと
```

## 9.2 固定年俸契約

複数年契約成立後は、契約期間中の年俸を毎年の成績から再計算しない。

- 長期契約：保障性が高い
- 短期契約：年俸がやや高いが再び市場へ出るリスクがある
- 延長契約：旧契約の残期間と新契約の開始年度を明示

契約中の昇降格が年俸へ与える影響は契約種別に従う。

## 9.3 市場評価

市場価格は基礎能力だけでなく、少なくとも次を評価する。

- 直近3年の実成績
- サンプル量
- 年齢
- 守位または投手役割
- 実際の出場機会
- 守備価値
- ケガとリハビリ
- 所属リーグ
- サービス年数

直近3年の重みは仕様で固定する。参考作品の台湾市場係数や金額式は使用せず、日本版の既存データで再校準する。

## 9.4 役割別評価

投手は同じ能力でも役割別に評価する。

| 役割 | 主な評価 |
| --- | --- |
| 先発 | 投球回、先発数、ERA、WHIP、勝利、奪三振 |
| 中継ぎ | 登板数、ホールド、ERA、WHIP |
| 抑え | セーブ、登板数、成功率、ERA、WHIP |

野手は打撃だけでなく守備位置の難度、実際の守備成績、出場量を評価する。DHが守備貢献を二重評価されないようにする。

## 9.5 最低保障

各リーグ・階層に最低年俸がある場合、次のすべてで同じ保障関数を使用する。

- 新規契約
- 更新
- FA
- 昇格後の契約
- 傷後の証明契約
- 守位係数適用後

係数適用の順番により最低保障を下回らないよう、最終段階で検証する。

## 9.6 放出・買い取り

球団都合で保障契約を途中終了する場合、残存年俸の扱いを契約時に説明する。

- 全額保障
- 一定割合の買い取り
- オプション破棄

どれを採用するかは日本語版の既存仕様を優先する。引退時と季末で二重入金しない。

## 9.7 オファー再抽選禁止

同一市場状態で「戻る」「再検討」を選んでも、球団、金額、年数を再抽選しない。市場オファーを生成した時点で保存し、交渉終了まで再利用する。

## 10. 収入の分類

### 10.1 内訳

```text
選手年俸
契約金
買い取り金
企業所属給与
広告・出演収入
その他収入
生涯総収入
```

### 10.2 原則

- ヘッダーは簡潔表示
- 詳細パネルは正確な金額
- 引退画面は内訳と総額
- 通貨が異なる場合は原通貨と内部換算を混同しない
- 譲渡金やポスティング費用は球団間支払であり選手収入へ含めない
- 給与入金後にヘッダーを即時更新する

### 10.3 表示例

```text

選手年俸累計：5億4,200万円
契約金累計：8,000万円
その他収入：1,300万円
生涯総収入：6億3,500万円
```

## 11. 成績データの物理的一貫性

## 11.1 投手

- 投球回は実際のアウト数で内部管理
- 表示時だけ`1/3`、`2/3`へ変換
- ERA、WHIP、被安打、四球、奪三振は同じ実アウト数を使用
- 救援投手の投球回が登板数や試合数を超えない
- 勝敗、セーブ、ホールドが登板機会を超えない
- 受傷や途中離脱後に全季分の成績を生成しない

## 11.2 野手

- 打席、打数、安打、本塁打、四球の関係を維持
- 盗塁は出塁機会と打席数の上限を超えない
- 守備評価は実際の出場試合数に応じて縮小
- 短期出場でシーズン満額の守備賞を取れない
- 五桁打席をWeb表と共有画像で切らない

## 11.3 共通検証

すべての能力補正、特性、ケガ、役割補正を適用した最後に物理上限を検証する。途中だけで上限処理すると、後段補正で再び超える可能性がある。

## 12. 年度表彰

### 12.1 二段階判定

1. 規定打席、規定投球回、出場数などの資格を判定
2. 資格者の中で実績とリーグ内支配度により受賞判定

### 12.2 リーグ別基準

同じERAや本塁打数をすべてのリーグへ共通適用しない。

- NPB
- MLB
- KBO
- 独立リーグ
- 社会人
- 高校
- 大学

試合数、リーグ平均、競争強度に合わせて基準を定義する。

### 12.3 同年度の受賞評価

生涯評価では、同一年に関連賞を複数受賞したときの二重加点を防止する。

例：

- 三冠王とMVP
- MVPとベストナイン
- 最優秀投手と投手三冠
- 金賞と守備部門賞

画面上の受賞歴はすべて残し、生涯評価点だけを年度単位で整理する。

### 12.4 新人賞

主要年度賞を先に判定し、新人年に圧倒的実績や複数主要タイトルを取った選手が新人賞だけ落とす不自然さを防ぐ。

## 13. 名人堂評価

## 13.1 実際に到達可能な分布で校準

固定能力値だけを直接投入したテストではなく、次を含む完全な生涯シミュレーションで校準する。

- 初期潜在能力
- 育成コスト
- ケガ
- 昇降格
- 出場機会
- 海外挑戦
- 衰退
- 実際の選択傾向

## 13.2 守位・役割別検証

- 中継ぎ
- 抑え
- 捕手
- 各内野守位
- 各外野守位
- 指名打者

## 13.3 得票率と入選年

得票率と入選年は、評価点が実際の名人堂線をどれだけ上回ったかに連動させる。

- 圧倒的な選手ほど早く入選
- 境界付近は長く待つ
- 落選者も名人堂線への距離に応じた最高得票率を表示
- 守位補正後の実際の門檻を使用
- 小さな乱数揺れだけを許可

画面用に別の固定門檻を持たない。

## 13.4 テスト指標

- 全体入選率
- 守位別入選率
- リーグ別入選率
- 役割別入選率
- 首回入選率
- 能力・潜在層別入選率
- 境界事例の代表的生涯

数値目標は日本語版の設計として別途決定し、YaKyoLifeの割合を直接採用しない。

## 14. Tommy Johnと投手負荷

### 14.1 負荷量表

投手には現在の肘負荷を表示できる。

```text
肘負荷：34 / 60
```

内訳候補：

- 先発投球回
- 救援登板数
- 投球強度
- 年齢
- 過去手術
- 休養
- 特性

### 14.2 役割別標準

先発は投球回、救援は登板数を基準に負荷を計算する。同じ式で単純比較しない。

### 14.3 選択が意味を持つこと

- 全力投球：負荷増、高成績期待
- 通常：標準
- 負荷軽減：負荷減、成績低下の可能性
- 先発から救援への転向
- 一時休養

選択に関係なく固定年数で必ず再発する処理を作らない。

### 14.4 手術回数別結果

手術回数ごとに影響を段階化できる。

- 初回：一般的な再建と復帰
- 2回目：復帰するが永久的損失の可能性
- 3回目以降：現役続行が非常に困難

具体的減少値、復帰率、発生頻度は日本版の固定seedシミュレーションで決定する。

### 14.5 表示一致

手術カードには次を表示する。

- 手術前能力
- 一時低下
- 回復量
- 永久低下
- 復帰後能力
- 欠場する年度

表示値を別計算せず、実際に状態へ適用した差分を表示する。

## 27. 最終方針

YaKyoLife v1.5.9から最も優先して学ぶべき点は、追加イベントの量ではなく、次の一貫性である。

1. 画面の説明と実際の計算を同じ値から作る
2. 契約を年俸だけでなく年数・総額・保障として見せる
3. 生涯の途中でも実績・契約・特性・年度別記録を確認できる
4. 成績に物理上限と資格条件を持たせる
5. 名人堂や市場を到達可能な生涯分布で校準する
6. 引退を数値表だけで終わらせず、生涯条件に合った物語で締める

日本語版では、まず背番号、詳細4タブ、契約表示、表示設定を導入候補とし、その後に市場、表彰、名人堂、TJ、イベント構成など結果を変える機能を独立バージョンで検討する。
