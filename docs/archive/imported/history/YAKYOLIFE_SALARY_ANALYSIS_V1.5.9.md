# YaKyoLife v1.5.9 球員薪資計算解析資料

> 解析對象：https://www.yakyolife.com/  
> 線上版本：v1.5.9  
> 確認日期：2026-08-30  
> 金額單位：萬台幣（除非另有說明）

---

## 1. 資料目的

本資料整理 YaKyoLife v1.5.9 的球員薪資、合約與自由市場計算方式，供下列用途確認：

- 確認球員年度薪資為何增加、維持或下降。
- 比較球員能力、實際成績、守位與投手角色對薪資的影響。
- 確認最近三季、傷病、年齡、球隊控制期與合約類型的倍率。
- 作為「野球人生シミュレーター」日本版薪資系統設計與修改時的參考。
- 區分基礎市場價值、實際合約年薪、簽約金與生涯收入。

本解析以線上公開 JavaScript 原始碼為準，不以畫面顯示文字反推公式。

## 2. 薪資計算總流程

```text
球員能力
  ↓
基礎成績評價 d
  ↓
工作量／守位／實際成績修正
  ↓
薪資專用評價 payD
  ↓
最近三季加權市場評價 marketRating
  ↓
跨層級評價換算
  ↓
聯盟基礎年薪公式 salaryFor
  ↓
傷病、長短約、球隊報價、特性等倍率
  ↓
最低年薪保障
  ↓
固定合約年薪 annual
```

### 2.1 重要結論

薪資不是直接使用畫面上的「綜合能力 OVR」計算，也不是只看當季打擊率、ERA 或勝場。

真正帶入薪資公式的是：

```text
最近三季加權後的薪資專用評價 payD
```

## 3. 基礎成績評價 d

### 3.1 投手

```text
d =（球速 + 控球 + 變化球）÷ 3 − 所屬層級平均值 par
```

體力不直接加入投手的基礎 `d`，但會影響：

- 是否能擔任先發投手。
- 出賽場次與投球局數。
- 先發工作量修正。
- 最終薪資評價 `payD`。

#### 投手計算例

日職一軍投手：

```text
球速 60、控球 57、變化球 58
日職一軍 par = 53

d =（60 + 57 + 58）÷ 3 − 53
  = 5.33
```

### 3.2 野手

```text
d = 打擊 × 0.50
  + 長打 × 0.20
  + 選球 × 0.18
  + 速度 × 0.12
  − 所屬層級平均值 par
  − 0.5
```

| 能力 | 權重 |
|---|---:|
| 打擊／Contact | 50% |
| 長打／Power | 20% |
| 選球／Eye | 18% |
| 速度／Speed | 12% |
| 體力 | 不直接計入 d |
| 守備 | 下一階段另外計算 |

體力雖然不直接加入 `d`，但會影響出賽數、打席與守備累積，因此仍可能間接影響薪資。

### 3.3 各層級平均值

| 代碼 | 層級 | par | 最低能力門檻 | 球季場次 |
|---|---|---:|---:|---:|
| CPBL2 | 中職二軍 | 34 | 30 | 80 |
| CPBL1 | 中職一軍 | 44 | 41 | 120 |
| NPB2 | 日職二軍 | 47 | 44 | 100 |
| NPB1 | 日職一軍 | 53 | 50 | 143 |
| R | 新人聯盟 | 41 | 39 | 55 |
| A1 | 1A | 45 | 43 | 110 |
| A2 | 2A | 49 | 47 | 120 |
| A3 | 3A | 54 | 52 | 130 |
| MLB | 大聯盟 | 59 | 56 | 162 |

## 4. 薪資專用評價 payD

球季結束後，系統會在基礎 `d` 上加入角色、工作量、守位及實際成績修正，產生 `payD`。

### 4.1 先發投手工作量修正

```text
工作量修正 = clamp（（投球局數 ÷ 聯盟場次 − 0.75）× 2，−1，+0.75）
```

修正範圍：

```text
最低 −1
最高 +0.75
```

#### MLB先發投手例

```text
投球局數 180
MLB 場次 162

（180 ÷ 162 − 0.75）× 2 = +0.72
```

### 4.2 終結者修正

```text
角色修正 = −2 + clamp（（救援數 − 25）÷ 20，−0.75，+0.75）
```

大約落在：

```text
−2.75 ～ −1.25
```

### 4.3 中繼投手修正

```text
角色修正 = −4 + clamp（（中繼成功數 − 20）÷ 20，−0.75，+0.75）
```

大約落在：

```text
−4.75 ～ −3.25
```

因此同樣基礎能力下，遊戲設計上的薪資排序通常是：

```text
先發投手 > 終結者 > 中繼投手
```

### 4.4 野手守位修正

```text
payD = d +（DEF + 守位價值 × 實際出賽比例）÷ 6 + 帳面成績修正
```

| 守位 | 滿季守位價值 | 僅守位對 payD 的影響 |
|---|---:|---:|
| 捕手 C | +9 | +1.50 |
| 游擊 SS | +7.5 | +1.25 |
| 中外野 CF | +5 | +0.83 |
| 二壘 2B | +3 | +0.50 |
| 三壘 3B | +2 | +0.33 |
| 右外野 RF | −5 | −0.83 |
| 左外野 LF | −7 | −1.17 |
| 一壘 1B | −10 | −1.67 |
| 指定打擊 DH | −14 | −2.33 |

上述數值還會依實際出賽場次折算，並加上球員真正產生的 `DEF` 守備貢獻。

### 4.5 實際帳面成績修正

只有日職一軍及 MLB 套用此項修正。中職、日職二軍和小聯盟不套用。

| 球季評等 | payD 修正 |
|---|---:|
| 無法評價／樣本不足 | 0 |
| 差 | −1 |
| 普通 | 0 |
| 好 | +1.25 |
| 壓倒性 | +3.25 |

#### 野手評等標準

| 評等 | 主要條件 |
|---|---|
| 無法評價 | 打席低於聯盟場次 × 2 |
| 壓倒性 | OPS ≥ .850；或 OPS ≥ .800 且全壘打達門檻 |
| 好 | OPS ≥ .750 |
| 普通 | OPS ≥ .650 |
| 差 | OPS < .650 |

#### 投手評等標準

| 評等 | 主要條件 |
|---|---|
| 無法評價 | 投球局數不足 |
| 壓倒性 | ERA ≤ 2.80 且工作量充足 |
| 好 | ERA ≤ 3.50；或 WHIP ≤ 1.15 且 ERA ≤ 3.75 |
| 普通 | ERA ≤ 4.35 |
| 差 | ERA > 4.35 |

#### 完整例

```text
MLB先發投手基礎 d       5.00
先發工作量修正          +0.70
壓倒性球季修正          +3.25
────────────────────────────
薪資專用 payD           8.95
```

此時薪資公式使用的是 `8.95`，不是原始 `d=5`，也不是畫面 OVR。

## 5. 最近三季市場評價

### 5.1 健康球員

```text
市場評價 = 本季 payD × 65%
         + 前一季 payD × 25%
         + 前兩季 payD × 10%
```

#### 例

```text
本季 payD：8
前一季：5
前兩季：3

市場評價 = 8 × 0.65 + 5 × 0.25 + 3 × 0.10
         = 6.75
```

### 5.2 不同傷病狀態的年度權重

| 市場狀態 | 本季 | 前一年 | 前兩年 |
|---|---:|---:|---:|
| 健康 | 65% | 25% | 10% |
| 小傷 | 55% | 30% | 15% |
| 重大傷勢 | 35% | 40% | 25% |
| 整季復健 | 20% | 50% | 30% |

重大傷勢或整季復健時，系統會降低當季權重，改為更重視傷前履歷。

### 5.3 資料不足時

若只有一季資料，會用現有年度的權重重新正規化，不會把不存在的前兩季直接當成零分。

## 6. 跨層級評價換算

`d` 是相對於所屬層級平均值的差距，因此轉往不同層級核薪時會先換算：

```text
目標層級評價 = 原評價 + 原層級 par − 目標層級 par
```

#### 例：3A轉MLB

```text
3A 評價 d = +8
3A par = 54
MLB par = 59

MLB換算評價 = 8 + 54 − 59
             = 3
```

因此不會把「3A高於平均8點」直接當成「MLB高於平均8點」。

## 7. 聯盟基礎年薪公式

### 7.1 負評價處理

帶入基礎年薪曲線前：

```text
raw = max（0，市場評價）
```

負數評價會先視為0，再由最低年薪保障處理。

### 7.2 中職一軍

```text
年薪 = 120 + raw × 65 + raw² × 3
```

### 7.3 日職一軍

日職先把超過15的評價壓縮：

```text
若 raw ≤ 15：p = raw
若 raw > 15：p = 15 +（raw − 15）× 0.35
```

再計算：

```text
年薪 = 360 + p × 280 + p² × 36
```

### 7.4 MLB

同樣使用壓縮後的 `p`：

```text
年薪 = 2,400 + p × 1,400 + p² × 600
```

## 11. 長約、短約與其他倍率

### 11.1 合約類型

| 類型 | 年薪倍率 | 特徵 |
|---|---:|---|
| 長約 | ×0.95 | 年薪略低，但保障年限較長 |
| 短約 | ×1.05 | 年薪較高，賭下次市場價值 |
| 證明約 | 依傷病倍率後再×1.05 | 通常只有1年 |

只有市場評價非負數、健康狀況允許且最長年限超過2年時，才會出現長約。

### 11.2 其他倍率

| 條件 | 倍率／影響 |
|---|---:|
| 神主牌／招牌球星與母隊續約 | ×1.04 |
| 使用交易否決權 | ×0.85 |
| 一般自由市場球隊報價 | 約×0.97～1.05 |
| 球團冷處理報價 | 傷病倍率後×0.90 |
| 無人報價回原隊 | 傷病倍率後×0.70 |
| 自由市場主動回原隊 | 傷病倍率後×0.90 |

倍率通常是相乘，而不是相加。

#### 例1：健康神主牌與母隊簽短約

```text
市場價 1,000萬

1,000 × 短約1.05 × 神主牌1.04
= 1,092萬
```

#### 例2：同一球員曾使用交易否決權

```text
1,000 × 1.05 × 1.04 × 0.85
= 約928萬
```

即使成績相同，也可能因特性懲罰而低於原市場價。

## 12. 合約年限

### 12.1 球員類型上限

| 類型 | 最長合約 |
|---|---:|
| 野手 | 15年 |
| 先發投手 | 7年 |
| 終結者 | 5年 |
| 中繼投手 | 4年 |

### 12.2 年齡上限

| 年齡 | 最長年限 |
|---|---:|
| 29歲以下 | 角色原上限 |
| 30～31歲 | 8年 |
| 32～33歲 | 5年 |
| 34～35歲 | 3年 |
| 36歲以上 | 2年 |

### 12.3 年限評價公式概念

```text
表現係數 = clamp（（市場評價 + 2）÷ 8，0，1）

基礎年限 = round（2 + 表現係數 ×（角色年限上限 − 2）
                    − 傷病歷史懲罰）
```

傷病歷史懲罰包括：

- 每次重大傷勢增加懲罰。
- 每次TJ手術增加更大懲罰。
- 再套用年齡與當前傷病狀態上限。

## 13. 固定合約與年度薪資

簽約完成後，合約會保存：

```text
合約年限 yrs
固定年薪 annual
年度年薪表 annualSchedule
合約倍率 mult
是否提前續約 extOffered
```

合約有效期間內，年薪原則上不會因下列因素每年重算：

- 當季成績變好。
- 當季成績變差。
- 能力上升或衰退。
- 受傷。
- 被下放。

可能改變年薪的時機：

- 合約到期重新簽約。
- 提前延長續約。
- 升級後低於新層級最低保障。
- 合約被買斷。
- 進入自由市場後選擇其他報價。

### 13.1 為何好成績卻沒有加薪

最常見原因是：

```text
球員仍在固定多年約內
```

當季好成績只會提高下一份合約的市場評價，不會改寫目前合約年薪。

### 13.2 為何好成績卻減薪

可能原因：

1. 前一份合約是在生涯高峰時簽下。
2. 最近三季加權後仍低於前次簽約評價。
3. 重大傷勢或復健造成市場折價。
4. 從短約高倍率改為長約低倍率。
5. 使用交易否決權產生15%懲罰。
6. 球團冷處理或自由市場沒有其他球隊報價。
7. 轉往更高層級時，評價已先依新層級 `par` 向下換算。
8. 投手角色由先發改成終結者或中繼。
9. 野手轉為一壘、左外野或DH，守位價值下降。

## 14. 簽約金與生涯收入

簽約金會直接加入生涯薪資／收入累計，但不等於固定年薪。

自由市場基本簽約金基準：

| 層級 | 基準簽約金 |
|---|---:|
| 中職一軍 | 200萬 |
| 日職一軍 | 800萬 |
| MLB | 2,000萬 |

實際簽約金會再乘：

```text
隨機倍率約0.8～1.3
× 傷病簽約金倍率
```

### 14.1 日美入札讓渡金

日職球員透過入札加盟MLB時，讓渡金另付給原球團，不計入球員生涯收入。

```text
保障總額前7.5億：20%
7.5億～15億部分：17.5%
超過15億部分：15%
```

金額門檻同樣以萬台幣計算。

## 15. v1.5.9發現的公式不一致

程式註解說明：

```text
d超過15後只計算超出部分的35%，避免二次曲線失控。
```

日職與MLB確實使用壓縮後的 `p`，但中職一軍仍使用未壓縮的 `raw`：

```javascript
case 'CPBL1':
  return Math.round(120 + raw * 65 + raw * raw * 3);
```

因此實際狀況是：

| 聯盟 | d>15後處理 |
|---|---|
| 中職一軍 | 不壓縮，維持完整二次曲線 |
| 日職一軍 | 超出15部分只計35% |
| MLB | 超出15部分只計35% |

### 15.1 判斷

可能性有兩種：

1. 中職刻意維持未壓縮曲線。
2. 原本應使用 `p`，但實作時誤用 `raw`。

由於註解描述的是「頂級聯盟」且共用函式已先產生 `p`，較可能是中職分支遺漏。不過一般中職球員很難達到 `d>15`，實際遊戲中不易發現。

## 16. 套用到日本版時的確認項目

「野球人生シミュレーター」若參考這套制度，建議先決定下列項目，不宜直接照搬台灣版數值。

| 確認項目 | 必須決定的內容 |
|---|---|
| 金額單位 | 全部改為萬日圓，或內部統一台幣後顯示換算 |
| NPB最低年薪 | 一軍、支配下、育成、二軍是否分開 |
| MLB薪資 | 顯示美元、日圓或遊戲統一貨幣 |
| 社會人 | 應算工作年薪、球員薪資，或兩者拆分 |
| 獨立聯盟 | 固定月薪、年度薪資或依出賽給付 |
| KBO | 是否建立獨立薪資曲線及最低薪資 |
| NPB控制期 | 是否使用逐年加薪、年俸調停或遊戲簡化比例 |
| MLB控制期 | 是否區分底薪、仲裁與FA年資 |
| 投手角色 | 中繼投手目前會被固定扣約3.25～4.75評價 |
| 守位價值 | 捕手／游擊加價及一壘／DH減價是否符合日本版需求 |
| 最近三季 | 65／25／10是否維持，或提高當季比重 |
| 傷病 | 是否依明星履歷降低傷病折價 |
| 固定合約 | 是否允許單年加薪，或多年約完全固定 |
| FA報價 | 是否限制報價不得低於現行年薪，或允許市場低價 |
| 年齡 | 30歲後合約年限上限是否符合日本版衰退曲線 |
| 跨聯盟換算 | 必須用各層級 `par` 換算，避免二軍成績被當成一軍成績 |

### 16.1 日本版特別需要注意

目前日本版已加入：

- NPB育成。
- 日本獨立聯盟。
- 日本社會人。
- KBO一軍與二軍。
- CPBL一軍與二軍。
- MLB與MiLB。

因此若只沿用三條薪資公式，以下層級會缺乏明確市場價值：

```text
NPB育成
日本獨立聯盟
日本社會人
KBO一軍
KBO二軍
CPBL一軍／二軍
```

這些層級需要另外設計：

1. 最低年薪。
2. 基礎年薪曲線。
3. 球隊控制期倍率。
4. 跨層級評價換算。
5. 是否能簽多年約。
6. 是否有簽約金。
7. 降級後是否保留原合約保障。

## 17. 薪資異常確認順序

玩家反映薪資不合理時，建議依此順序確認：

1. 確認目前是否仍在固定多年約。
2. 確認當季 `d`、`payD` 與 `marketRating`。
3. 確認最近三季實際使用的權重。
4. 確認投手角色或野手守位是否改變。
5. 確認日職／MLB帳面成績評等是否為差、普通、好或壓倒性。
6. 確認是否為小傷、重大傷勢或復健狀態。
7. 確認是否仍處於球隊控制期。
8. 確認長約、短約、神主牌及交易否決倍率。
9. 確認是否為球團冷處理、無人報價或回原隊折價。
10. 確認跨聯盟或跨層級時是否已換算 `par`。
11. 確認最低年薪是否正確套用。
12. 確認畫面顯示的是年度薪資、簽約金、合約總額或生涯累計。

## 18. 核心公式速查

```text
【投手基礎d】
d =（球速 + 控球 + 變化球）÷ 3 − par

【野手基礎d】
d = 打擊×0.50 + 長打×0.20 + 選球×0.18 + 速度×0.12 − par − 0.5

【野手payD】
payD = d +（DEF + 守位價值×出賽比例）÷6 + 成績評等修正

【健康市場評價】
marketRating = 本季payD×0.65 + 前季×0.25 + 前兩季×0.10

【跨層級換算】
目標評價 = 原評價 + 原層級par − 目標層級par

【中職一軍】
salary = 120 + raw×65 + raw²×3

【日職一軍】
salary = 360 + p×280 + p²×36

【MLB】
salary = 2,400 + p×1,400 + p²×600

【高評價壓縮】
p = raw（raw≤15）
p = 15 +（raw−15）×0.35（raw>15）

【最終年薪】
annual = round（max（層級最低年薪，salary×合約倍率））
```

## 20. 最終結論

YaKyoLife v1.5.9的年薪可概括為：

```text
聯盟薪資曲線
× 最近三季的球員市場評價
× 傷病與合約倍率
```

其中球員市場評價包含：

- 投打核心能力相對聯盟平均的差距。
- 投手角色與實際工作量。
- 野手守位與守備貢獻。
- 日職／MLB的實際帳面成績。
- 最近三季加權。
- 跨層級強度換算。

簽下合約後則轉為固定保障年薪，不會每一季自動依成績重新計算。因此判斷加薪、減薪或維持不變時，必須同時確認「市場價值」與「現行合約」兩個不同概念。
