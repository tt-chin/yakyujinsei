## 1. 目的

台湾版 v1.5.7 で追加・変更された機能を、日本語版 JP3 の確定仕様を壊さず導入する。台湾版固有の球界事情、球団文化、通貨、代表、引退描写、ネット用語はそのままコピーせず、日本の野球文化と日本語インターネット文化に合わせてローカライズする。

本書の承認前は、日本語版 `index.html` を変更しない。

## 2. 非交渉条件

以下は v1.5.7 より日本語版 JP3 を優先する。

- 更新前の基準は`RULES_VERSION="JP3"`、更新後の内部規則版は`JP4`
- `RNG_VERSION=1`は維持するが、共有URLには規則版・RNG版を含めない
- `stage` は `HS / U / CORP / IND / PRO`。旧 `AMA` は復活させない
- 社会人野球と独立リーグを別経路として扱う
- NPB育成、NPB二軍・一軍、KBO、CPBL、MiLB、MLBのJP3階層値
- 総合30未満の強制引退
- 戦力外後の候補最大4件、MiLB R～2Aの年齢制限
- 組織間移動は「海外移籍オファー」。一般トレードと混同しない
- MLB獲得条件 `o >= 60 && d >= 2`
- 高校卒業後のMiLB直接契約経路
- NPB中心の年俸、殿堂、引退評価
- NPB引退時に台湾人助っ人前提の「通訳」「異国で戦った日々」等を使用しない
- MLB時の母国報道は日本のスポーツメディアとする
- 台湾限定イベントはCPBL在籍実績などの条件を満たす場合だけ表示する

## 4. 実装方式

### 4.1 全面置換禁止

v1.5.7は旧版から行数・構造が大幅に増え、UI、状態、イベント、傷病、契約、引退処理が分割整理されている。台湾版HTMLを日本語版へ上書きすると、JP3固有ロジックが消失するため禁止する。

### 4.2 導入順

1. 状態項目と後方互換初期値
2. UI／レスポンシブ骨格
3. 特性表示基盤
4. イベントカード
5. TJ・一般傷病
6. 契約／年俸／移籍
7. 表彰／国際大会
8. 年表／引退／殿堂
9. シェア画像
10. 翻訳・用語最終審査

各段階で構文試験、開始から引退までの完走試験、固定シード試験を行う。

## 5. 状態データと互換性

新規状態値は必ず未定義時の初期値を持たせる。候補には `traits`、`removed`、TJ累積値・手術回数、契約状態、在籍年数、年表、外部収入、殿堂投票情報、UI設定が含まれる。

- 共有URLは台湾版方式の`?seed=...`だけを使用する
- 実行時は常に配信中の最新規則を使用し、旧JP1／JP2／JP3エンジンを保持しない
- ゲーム更新後に同じseedで同じ人生を完全再現できることは保証しない
- 旧URLに`rv`や`rules`が残っていても規則切替には使用せず、seedだけを読み取る
- 表示専用処理ではゲーム用乱数 `R()` を消費しない

## 6. 翻訳・ローカライズ規則

### 6.1 翻訳単位

すべての追加表示文を次の区分で管理する。

| 原文区分 | 翻訳方針 |
|---|---|
| UIラベル | 短く標準的な日本語 |
| 野球制度・記録 | NPBで一般的な正式用語 |
| 実況・新聞 | 日本のスポーツ紙調 |
| SNS・掲示板 | 5ちゃんねる、X、まとめサイト等の自然なネット口調 |
| 選手・監督の発言 | 年齢・立場に合う口語 |
| 台湾限定文化 | 日本相当へ置換、CPBL限定化、または不採用 |

### 6.2 5ちゃんねる系表現

逐語訳は禁止する。意味と使用場面が一致する場合だけ、例えば次のような日本語ネット表現を使用できる。

| 中文語感 | 日本語候補 | 備考 |
|---|---|---|
| 笑死／太好笑 | 草／草生える | 掲示板・SNS限定 |
| 炎上 | 炎上 | そのまま使用可 |
| 神操作／神表現 | 神采配／神ってる | 野球文脈に合わせる |
| 戰犯 | 戦犯 | 強い語なのでファン投稿限定 |
| 被打爆 | ボコボコ／大炎上 | 投手なら「大炎上」を優先 |
| 穩了 | 勝ったな／これはもろたで | 投稿者の口調に合わせる |
| 玻璃人 | スペ体質 | 選手特性名の候補 |
| 愛將 | 愛人枠 | 監督起用を揶揄する文脈限定 |

一般UI、公式発表、説明文にはネットスラングを混ぜない。

### 6.3 対応語がない場合

- 意味・温度感・使用場面の三つが一致する日本語がない場合、日本語欄は空欄にする
- 推測訳を実装しない
- 「未確定翻訳一覧」に原文、出現箇所、直訳、問題点を記録してユーザーへ確認する
- 空欄のまま画面へ出すのではなく、その文を含む機能の実装を保留する

### 6.4 固有ローカライズ

- 台幣／新台幣 → 円。金額は単純な文字置換ではなくゲーム内経済基準で換算
- 中華隊／Team Taiwan → 日本代表／侍ジャパン（大会・商標文脈により選択）
- 中職 → CPBL（CPBL在籍時）またはNPB（主軸イベント）
- 台灣媒體 → 日本のスポーツ紙・テレビ・ネットメディア
- 台湾球場・都市・球団文化 → 日本版の所属先に応じた可変文

## 8. 傷病・TJ仕様

- 投手の登板量、役割、投球方針、球速・変化球、手術歴からTJ負荷を累積
- 通常上限60、特性による上限120は移植候補
- 閾値到達時に能力低下後、手術または注射で続行を選択
- 初回、2回目、3回目で結果を変える
- 手術翌季のリハビリ、契約市場評価への影響を持たせる
- 文言は「TJ手術」または「トミー・ジョン手術」に統一
- 医学的断定を避け、ゲーム上の架空処理であることを前提とする

## 9. 契約・移籍統合

v1.5.7の市場価値・契約年数・故障歴評価は導入候補とするが、金額の基礎式はJP3を優先する。

- NPB一軍年俸の二次加算は整数 `d=8` から開始
- 同一リーグ／組織内の移動のみトレード
- NPB、KBO、CPBL、MLB等を跨ぐ移動は海外移籍オファー
- 海外FA候補は各組織を独立判定し、MLBが候補上限の順序で消えないようにする
- NPB育成とMiLB R～2Aの年齢制限を維持
- フランチャイズ特性のトレード保護は海外移籍・FAを自動禁止しない

## 10. 引退・殿堂

v1.5.7の引退演出、第二の人生、殿堂得票表示を導入する。ただし本文は日本人選手を主語として書き直す。

| リーグ | JP3殿堂最低点 |
|---|---:|
| NPB | 7,500 |
| KBO | 8,000 |
| CPBL | 8,500 |
| MLB | 7,500 |

- KBOは「韓国プロ野球殿堂」を追加
- NPBは「日本野球殿堂」
- 複数リーグ同時入選を許可
- 台湾版の固定得票母数は日本版で再検討し、少なくともKBOを欠落させない
- NPB引退文から中国語、通訳、異国生活を削除
- CPBL在籍時だけ台湾での別れ・報道を表示可能

### 12.1 同一球団在籍称号との重複整理

現行JP3には同一NPB球団10年の称号がないため、JP4で新設する。

| 称号 | 現行条件 |
|---|---|
| 球団の顔（`franchise`） | 同一球団に連続7年以上在籍し、その球団で優勝経験がある |
| ○○一筋（`goldcloth`の置換） | 同一NPB球団に連続10年以上在籍し、職業生涯で他の一軍球団に所属していない。成績・優勝経験は問わない |
| ○○ミスター（`mrteam`） | 同一球団に15年以上在籍し、直近評価`d>=0` |

台湾版の`goldcloth`（特定CPBL球団の固有ネタ）はそのまま移植しない。内部キーは互換性のため維持し、日本語版ではNPB用称号`○○一筋`として再定義する。NPB育成・二軍・一軍の移動は同一球団内なら継続扱いとする。他球団の育成・二軍・一軍または他国リーグへ移籍した時点で取得資格を失う。`○○`には対象球団の短縮名または愛称を動的表示する。取得後の移籍では称号を保持し、取得球団名も保存する。

### 12.2 共有URLと再現性

共有は台湾版v1.5.7と同じseed方式を採用する。

```text
https://<日本語版正式URL>/?seed=<SEED>
```

- URLへ`rv`、`rules`、アプリ版数を付与しない
- 同じseedでも、ゲーム更新後は同じ人生を完全再現できない
- JP3とJP4の二重エンジンは実装しない
- 共有ボタン名は`リプレイURLをコピー`とするが、永久再現は保証しない
- ゲーム開始時はURLのseedを読み、配信中の最新規則で実行する
- 新しい人生はseedを新規生成し、同じseedで再挑戦する場合は現在のseedを再利用する
