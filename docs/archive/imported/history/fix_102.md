## 2. 目的

1. NPB殿堂評価で国際大会の「準優勝」が「優勝」と誤判定され、100点多く加算される不具合。
2. 集中育成判定の対象範囲について、実際の処理と一致していないコードコメント。

## 3. 不具合1: 国際大会準優勝の得点誤判定

### 3.1 現在の問題

`docs/src/engine/hall-of-fame-policy.js` のNPB国際大会加点は、現在おおむね次の順序になっている。

```javascript
if (honor.includes('優勝')) sc += 200;
else if (honor.includes('準優勝')) sc += 100;
```

日本語の `準優勝` は文字列として `優勝` を含むため、準優勝記録も最初の条件に一致する。

その結果、次のように誤計算される。

```text
正しい準優勝得点: +100
現在の得点:       +200
過剰加算:         +100
```

対象となる国際大会:

- ワールド・ベースボール・クラシック
- WBSCプレミア12

### 3.2 修正方法

少なくとも `準優勝` を `優勝` より先に判定すること。

```javascript
if (honor.includes('準優勝')) sc += 100;
else if (honor.includes('優勝')) sc += 200;
```

同等以上に安全な実装として、結果部分を明示的に判定してもよい。ただし、今回の修正範囲を超える大規模なリファクタリングは行わないこと。

### 3.3 維持する国際大会評価仕様

次の現行仕様は変更しないこと。

- 国際大会実績を殿堂評価へ加算するのはNPBだけ。
- 日本代表出場1大会につき `+80`。
- 優勝は `+200`。
- 準優勝は `+100`。
- ベスト4・ベスト8は結果ボーナス `0`。
- KBO・CPBL・MLBの殿堂評価へ国際大会得点を加算しない。
- `intlCount` の増加条件を変更しない。
- 国際大会の開催年、出場条件、結果抽選、能力点、故障率を変更しない。

### 5.3 集中育成仕様の変更禁止

## 6. 不具合3: 国内大会の参加条件と大学大会能力点

### 6.1 共通の重大不具合: `準優勝` が `優勝` として扱われる

現在の国内大会処理では、後続大会への進出判定におおむね次の処理を使用している。

```javascript
rows.at(-1)?.includes('優勝')
```

日本語の `準優勝` は文字列として `優勝` を含むため、準優勝でも優勝扱いとなる。これにより、少なくとも次の誤進出が起こり得る。

- 夏の地方大会準優勝から全国高校野球選手権大会へ進出する。
- 大学春季リーグ準優勝から全日本大学野球選手権大会へ進出する。
- 今後同じ方式を使う場合、他の予選・代表決定処理でも同じ誤判定が起こる。

表示用HTML文字列をゲーム判定へ使用してはならない。`cupOnce()` は文字列だけでなく、少なくとも次のような構造化結果を返すようにすること。

```javascript
{
  html,
  result,       // '優勝' | '準優勝' | 'ベスト4' | 'ベスト8' | '予選敗退'
  resultIndex,
  isChampion,
  points
}
```

後続大会への進出は、次のような完全一致または真偽値で判定すること。

```javascript
result.result === '優勝'
// または
result.isChampion === true
```

`includes('優勝')` を国内大会の資格判定に残してはならない。

### 6.2 高校大会の年度順序と参加条件

現在は秋季地区大会、選抜高校野球大会、夏の地方大会の順で同一年内に処理され、選抜大会は `S.stageYr >= 2` だけで自動参加となっている。三年生も夏の大会後に秋季大会へ参加し得る。

高校大会は次の順序と条件へ変更すること。

| 順序 | 大会 | 参加条件 | 能力点 |
| --- | --- | --- | --- |
| 1 | 選抜高校野球大会 | 高校2・3年生で、前年秋季地区大会から選抜資格を得ている | 現行維持 |
| 2 | 夏の地方大会 | 高校1～3年生全員 | 現行維持 |
| 3 | 全国高校野球選手権大会 | 同年の夏の地方大会で優勝 | 現行維持 |
| 4 | 秋季地区大会 | 高校1・2年生のみ | 現行維持 |

選抜大会は実際には秋季大会の結果・試合内容等をもとに選考され、単純な固定順位制ではない。本ゲームでは再現可能で理解しやすい簡略ルールとして、秋季地区大会の次の結果を翌年の選抜資格とする。

```text
優勝・準優勝・ベスト4
→ 翌年の選抜高校野球大会へ出場

ベスト8・予選敗退
→ 翌年の選抜高校野球大会へ出場しない
```

前年の資格を次年度へ引き継ぐため、状態に専用フィールドを追加すること。例:

```javascript
senbatsuEligibleYear: null
```

秋季大会終了時に、資格を取得した場合だけ次年度を保存する。

```javascript
S.senbatsuEligibleYear = S.year + 1;
```

選抜大会の参加判定は次の意味になるよう実装すること。

```javascript
S.stage === 'HS' &&
S.stageYr >= 2 &&
S.senbatsuEligibleYear === S.year
```

注意事項:

- 高校3年生は夏季大会終了後に秋季地区大会へ参加させない。
- 高校1年生の秋季結果は高校2年春へ、高校2年生の秋季結果は高校3年春へ引き継ぐ。
- 選抜大会出場後は使用済み資格をクリアし、再使用しない。
- 高校大会の能力点計算式・上限・総合能力加算・全国大会加算は変更しない。

### 6.3 大学大会の参加条件

大学大会は次の条件へ変更すること。

| 順序 | 大会 | 参加条件 |
| --- | --- | --- |
| 1 | 春季リーグ戦 | 大学1～4年生全員 |
| 2 | 全日本大学野球選手権大会 | 同年の春季リーグ戦で優勝 |
| 3 | 秋季リーグ戦 | 大学1～4年生全員 |
| 4 | 明治神宮大会・大学の部 | 秋季リーグ優勝後、所属経路に従って代表資格を得た場合のみ |

全日本大学野球選手権大会は、春季リーグ戦の `isChampion === true` の場合だけ実行すること。準優勝を進出させてはならない。

明治神宮大会は現在の無条件参加を廃止する。大学データへ次のような出場経路を追加すること。

```javascript
jinguRoute: 'DIRECT' | 'PLAYOFF'
```

現在収録されている大学の簡略分類は次のとおりとする。

- `U_001`～`U_006`（東京六大学相当）: `DIRECT`
- `U_007`～`U_010`（東都大学相当）: `DIRECT`
- `U_011`～`U_025`: `PLAYOFF`

神宮大会への進出フロー:

```text
秋季リーグ優勝ではない
→ 明治神宮大会へ出場しない

秋季リーグ優勝 + DIRECT
→ 明治神宮大会へ出場

秋季リーグ優勝 + PLAYOFF
→ 地区代表決定戦を行う
   → 代表資格獲得: 明治神宮大会へ出場
   → 敗退: 明治神宮大会へ出場しない
```

地区代表決定戦は参加資格だけを判定し、能力点を付与しないこと。結果は画面およびキャリア年表へ表示すること。

### 6.4 大学大会の能力点を1～5点へ変更

大学在籍中に実行される次の4大会は、結果に応じた能力点を固定で `1～5` とする。

- 春季リーグ戦
- 全日本大学野球選手権大会
- 秋季リーグ戦
- 明治神宮大会・大学の部

| 結果 | 大学大会能力点 |
| --- | ---: |
| 優勝 | 5 |
| 準優勝 | 4 |
| ベスト4 | 3 |
| ベスト8 | 2 |
| 予選敗退 | 1 |

大学大会では現在の次の加算を行わない。

```javascript
Math.floor(ovr() / 22)
national ? 1 : 0
```

したがって「基本点が1～5」ではなく、加算後の最終獲得量も必ず1～5点とする。大会結果の強さ判定には現行の総合能力・学校ランク・乱数を使用してよいが、それを能力点へ加算してはならない。

高校・社会人・独立リーグ・国際大会の能力点は今回変更しない。共通関数を使う場合は、大学だけ異なる点数モードを明示すること。例:

```javascript
cupOnce(key, name, klass, { pointMode: 'UNIVERSITY' });
```

### 6.5 社会人大会の参加条件

現在は、JABA地区大会、都市対抗野球大会、社会人野球日本選手権大会へすべて無条件で参加している。次の簡略ルールへ変更すること。

| 大会・予選 | 参加条件・役割 | 能力点 |
| --- | --- | --- |
| JABA地区大会 | 現行どおり社会人チームが参加 | 現行維持 |
| 都市対抗地区予選 | 社会人チームが参加し、都市対抗本大会の資格を判定 | なし |
| 都市対抗野球大会 | 都市対抗地区予選で代表資格を取得 | 現行維持 |
| 日本選手権地区最終予選 | JABA地区大会・都市対抗で出場権を得ていない場合に実施 | なし |
| 社会人野球日本選手権大会 | JABA地区大会優勝、都市対抗優勝、または地区最終予選で出場資格獲得 | 現行維持 |

予選・代表決定戦は資格判定だけを行い、能力点を付与しない。結果は画面およびキャリア年表へ表示すること。

### 6.6 独立リーグ大会の参加条件

現在は独立リーグ公式戦の結果に関係なくグランドチャンピオンシップへ参加する。次の条件へ変更すること。

```text
独立リーグ公式戦優勝
→ グランドチャンピオンシップへ出場

準優勝・ベスト4・ベスト8・予選敗退
→ 出場しない
```

判定には表示文字列ではなく `isChampion` を使用する。独立リーグ大会の能力点は現行のままとする。

### 6.7 国内大会修正に伴う実装上の制約

- `cupOnce()` の戻り値を構造化しても、画面表示とキャリア年表の既存情報を欠落させない。

- 大会以外のFA、年俸、移籍、昇降格、殿堂、引退ロジックを変更しない。
