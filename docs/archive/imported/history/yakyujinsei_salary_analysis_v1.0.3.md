# 野球人生模擬器：球員薪資計算解析

- 解析網站：<https://yakyujinsei.com/>
- 對象版本：`v1.0.3`
- 解析日期：2026-08-30
- 金額單位：日圓；表格與公式主要使用「萬日圓」

## 1. 結論摘要

網站的球員年薪不是直接將打擊率、全壘打、ERA、勝投等數據逐項換算成金額，而是先依球員能力相對於所屬層級平均水準算出評價值 `d`，再依序套用：

1. 當年度獎項加成。
2. 所屬層級的基礎薪資曲線。
3. 合約係數。
4. 野手守位係數。
5. 四捨五入至一萬日圓。

整體流程如下：

```text
球員能力
  ↓
計算相對聯盟水準的評價值 d
  ↓
加入當年度獎項加成
  ↓
向下取整並限制為 0～26
  ↓
套用所屬層級薪資公式
  ↓
套用合約係數
  ↓
套用守位係數（野手）
  ↓
四捨五入至 1 萬日圓
  ↓
決定下一年度年薪
```

## 2. 薪資評價值 p

薪資計算不會直接使用原始 `d`，而是先加入當年度獎項加成，再向下取整：

$$
p=\operatorname{clamp}\left(\left\lfloor d+\text{獎項加成}\right\rfloor,0,26\right)
$$

其中：

- `floor`：向下取整。
- `clamp`：將結果限制在 0～26。
- 負數一律以 0 計算。
- 超過 26 一律以 26 計算。

例如：

```text
d = 6.8，沒有獎項 → p = 6
d = 6.8，獎項 +1 → p = 7
d = 6.8，獎項 +2 → p = 8
d = -3.0 → p = 0
d = 30.0 → p = 26
```

## 3. 投手評價值 d

投手公式：

$$
d=\frac{球速+控球+變化球}{3}-所屬層級平均水準
$$

投手體力不直接進入 `d`，但會影響先發局數、登板數與出賽量。

### 範例

NPB 一軍平均水準為 58：

```text
球速：65
控球：60
變化球：61

d = (65 + 60 + 61) ÷ 3 - 58
  = 4
```

## 4. 野手評價值 d

野手公式：

$$
d=0.50\times Contact+0.20\times Power+0.18\times 選球眼+0.12\times 速度-所屬層級平均水準-0.5
$$

權重如下：

| 能力 | 權重 |
|---|---:|
| Contact／打擊接觸 | 50% |
| Power／長打力 | 20% |
| 選球眼 | 18% |
| 速度 | 12% |

守備能力不直接進入 `d`，但守備位置會在最後影響年薪係數。

### 範例

NPB 一軍野手：

```text
Contact：65
Power：60
選球眼：58
速度：55
所屬層級平均：58
```

$$
d=65(0.5)+60(0.2)+58(0.18)+55(0.12)-58-0.5=3.04
$$

沒有獎項時，薪資計算使用 `p = 3`。

## 5. 生涯年與低潮年

每季可能出現狀態修正：

| 狀態 | d 修正 |
|---|---:|
| 生涯年 | +4 |
| 正常球季 | 0 |
| 低潮年 | -4 |

因此生涯年可能讓球員直接跨入明星薪資區間；低潮年則可能導致下一年度大幅減薪。

## 6. 各層級平均水準

`par` 是該層級的平均能力水準，也是計算 `d` 時扣除的基準。

| 層級 | `par` |
|---|---:|
| NPB 育成 | 35 |
| NPB 二軍 | 52 |
| NPB 一軍 | 58 |
| KBO 二軍 | 39 |
| KBO 一軍 | 50 |
| CPBL 二軍 | 39 |
| CPBL 一軍 | 48 |
| 美國新人聯盟 | 43 |
| 1A | 47 |
| 2A | 51 |
| 3A | 56 |
| MLB | 63 |

能力完全相同的球員，移往水準更高的聯盟後，`d` 會降低；不過新合約的額外係數仍可能讓最終薪資上升。

## 7. 獎項加成

當年度獎項會直接增加薪資評價值，單季合計最多增加 3。

### 加 2 點

- 年度 MVP（年間MVP）
- 年度最佳投手（最優秀投手賞）
- 澤村賞（沢村賞）

### 加 1 點

- 勝投王（最多勝）
- 防禦率王（最優秀防御率）
- 三振王（最多奪三振）
- 救援王（最多セーブ）
- 中繼王（最優秀中継ぎ）
- 打擊王（首位打者）
- 全壘打王（本塁打王）
- 打點王（打点王）
- 上壘率王（最高出塁率）
- 盜壘王（盗塁王）
- 金手套（ゴールデングラブ賞）
- 年度最佳守備球員（年間最優秀守備選手）

### 獎項不減薪保護

如果當年度獎項加成合計達到 2 以上，下一年度年薪不得低於目前年薪。

| 得獎情況 | 評價加成 | 不減薪保護 |
|---|---:|---|
| 一個 MVP／最佳投手／澤村賞 | +2 | 有 |
| 兩個一般個人獎 | +2 | 有 |
| 一個一般個人獎 | +1 | 無 |
| 多個獎項合計超過 3 | 最高 +3 | 有 |

## 8. 基礎薪資公式

令：

$$
s=\max(0,p-7)
$$

一般公式為：

$$
基礎年薪=B+L\times p+Q\times s^2
$$

其中 `s²` 是明星級球員的二次方加成，只有 `p > 7` 才會生效。

以下單位為萬日圓，尚未套用合約與守位係數。

| 層級 | 基礎年薪公式 |
|---|---|
| 獨立聯盟 | $240+10p$，設定上限 500 |
| NPB 育成 | 固定 300 |
| NPB 二軍 | $500+30p$ |
| NPB 一軍 | $1600+400p+300s^2$，上限 60,000 |
| KBO 二軍 | $800+40p$ |
| KBO 一軍 | $4000+800p+200s^2$ |
| CPBL 二軍 | $400+20p$ |
| CPBL 一軍 | $1200+300p+80s^2$ |
| 美國新人聯盟 | 固定 300 |
| 1A | 固定 400 |
| 2A | 固定 600 |
| 3A | $1000+50p$ |
| MLB | $12000+3000p+1200s^2$ |

## 11. 野手守位係數

| 守位 | 年薪係數 |
|---|---:|
| 游擊手 | ×1.15 |
| 中外野手 | ×1.15 |
| 捕手 | ×1.12 |
| 二壘手 | ×1.05 |
| 三壘手 | ×1.05 |
| 右外野手 | ×1.05 |
| 一壘手 | ×1.00 |
| 左外野手 | ×1.00 |
| 指定打擊 | ×0.92 |
| 投手 | ×1.00 |

例如 NPB 一軍 `p = 10` 時，基礎年薪為 8,300 萬日圓：

| 守位 | 計算 | 年薪 |
|---|---|---:|
| 游擊手 | $8300\times1.15$ | 9,545萬 |
| 捕手 | $8300\times1.12$ | 9,296萬 |
| 一壘手 | $8300\times1.00$ | 8,300萬 |
| DH | $8300\times0.92$ | 7,636萬 |

## 12. 合約係數

最終薪資還會乘上合約倍率。

| 合約情況 | 係數 |
|---|---:|
| 一般合約 | ×1.00 |
| 國內 FA 報價 | ×1.25 |
| 海外／跨聯盟報價 | ×1.30 |
| FA 宣告後留原隊 | ×1.10 |
| FA 無報價後回原隊 | ×0.90 |

### 提前延長合約

提前延長時先依成績決定基礎係數：

| 評價 | 基礎係數 |
|---|---:|
| `d ≥ 3` | 1.20 |
| `0 ≤ d < 3` | 1.00 |
| `d < 0` | 0.80 |

再依合約類型調整：

- 長約：基礎係數 ×0.92。
- 短約：基礎係數 ×1.12。
- 招牌球員：基礎係數最低為 1.20。
- 交易否決權成本：再乘 0.85。

例如 `d ≥ 3`：

```text
長約係數：1.20 × 0.92 = 1.104，程式顯示約 1.10
短約係數：1.20 × 1.12 = 1.344，程式顯示約 1.34
```

短約的年薪比較高，但保障年數較少。

## 13. 最終年薪公式

程式實際採用的候選年薪可整理為：

$$
最終候選年薪=round_{1萬}\left(round_{1萬}(基礎年薪)\times 合約係數\times 守位係數\right)
$$

其中：

- 投手守位係數固定為 1。
- 野手若尚未決定細部守位，係數通常視為 1。
- 基礎年薪先套用該層級上下限。
- 合約及守位倍率在基礎上限後才套用。

## 14. 完整算例

假設一名 NPB 一軍游擊手：

```text
Contact：68
Power：62
選球眼：60
速度：57
當年度取得打擊王
一般合約
```

### 第一步：計算 d

$$
d=68(0.5)+62(0.2)+60(0.18)+57(0.12)-58-0.5=5.54
$$

### 第二步：加入獎項

打擊王增加 1：

$$
p=\lfloor5.54+1\rfloor=6
$$

### 第三步：計算 NPB 一軍基礎年薪

`p ≤ 7`，不會產生二次方加成：

$$
1600+400\times6=4000
$$

基礎年薪為 4,000 萬日圓。

### 第四步：套用游擊手係數

$$
4000\times1.15=4600
$$

一般合約的最終年薪為 4,600 萬日圓。

若是係數 1.34 的短期明星合約：

$$
4000\times1.15\times1.34=6164
$$

最終年薪約為 6,164 萬日圓。

## 15. 薪資支付與更新時點

球季結束時的流程為：

1. 先支付畫面顯示的「目前年薪」。
2. 將本季支付年薪加入生涯收入。
3. 依本季 `d`、獎項、下一季層級、守位及合約重新計算。
4. 新年薪從下一球季開始支付。

因此，本季打出生涯年不會回頭增加已經支付的本季年薪，而是提高下一年度年薪。

受傷或整季缺賽時，本季仍會支付既定的目前年薪；但下一年度可能因 `d` 降低而重新計算為較低金額。

## 16. 升格、降級與減薪保護

### 升格

升格後使用新層級重新計算，而且程式設定新年薪不得低於原年薪。

```text
升格年薪 = max（新層級候選年薪，目前年薪）
```

### 一般休賽季

如果沒有不減薪保護，下一年度年薪可以依最新評價上升或下降。

### 不減薪保護來源

- 升格。
- 當年度獎項加成達 2 以上。
- 球團主動續約。
- 部分提前延長或留隊流程。

### 降級

降級後會依較低層級重新計算；若沒有獎項或球團續約保護，可能大幅減薪。

## 18. 社會人球員收入

社會人球員不使用一般的 `d` 薪資曲線，而是依綜合能力 OVR 計算：

$$
年薪=420萬+(OVR-40)\times15萬
$$

限制如下：

- 最低 420 萬日圓。
- 最高 900 萬日圓。
- 四捨五入至 1 萬日圓。

例如 OVR 55：

$$
420+(55-40)\times15=645萬
$$

## 19. 生涯收入

目前程式會加入生涯收入的主要項目包括：

- 每季實際支付年薪。
- NPB 選秀簽約金。
- FA／跨聯盟簽約金。
- 合約買斷金。
- 社會人企業薪資。

### 合約買斷

- 球員主動或雙方協議解除：支付剩餘合約約 70%。
- 球團主動解除：支付剩餘合約 100%。

## 20. 現行程式值得注意的事項

### 20.1 薪資不直接依實際成績逐項換算

ERA、OPS、全壘打、勝投等不會直接換算金額。實際成績主要影響獎項；薪資核心仍是能力相對所屬層級水準的 `d`。

因此可能發生：

- 實際數據很好，但能力評價提升有限，薪資漲幅不大。
- 能力很高但隨機成績普通，仍可能取得高薪。
- 得獎會大幅改善實際成績與薪資評價之間的落差。

### 20.2 複數年合約不是完全固定年薪

合約會保存年限、年薪及總額，但每個休賽季仍可能依最新評價更新 `annualSalary` 與 `totalValue`。

因此目前的複數年合約比較接近：

> 固定年限＋固定合約倍率，但年薪基礎可能每年重算。

而不是現實中每年金額完全固定的保障合約。

### 20.3 基礎薪資上限不等於最終年薪上限

基礎薪資先限制上限，之後才套用守位與合約係數。

例如 NPB 基礎年薪已達 6 億日圓的游擊手，取得 1.30 倍合約時：

$$
6億\times1.15\times1.30=8.97億日圓
$$

### 20.4 獨立聯盟收入可能未正式入帳

程式中存在獨立聯盟薪資模型，但球季結束的收入入帳流程只明確處理職業球員及社會人球員。依目前流程，獨立聯盟薪資似乎沒有加入生涯收入，可能是尚未接上的功能。

### 20.5 合約買斷額可能與畫面年薪不同

買斷金重新使用所屬層級公式及合約倍率計算，沒有完整使用：

- 畫面上的目前年薪。
- 守位係數。
- 當年度獎項加成。

因此部分情況下，買斷金可能與畫面顯示的剩餘合約價值不完全一致。

### 20.6 單一一般獎項沒有不減薪保護

一個打擊王、全壘打王或金手套只會增加 1 點薪資評價。只有加成合計達 2 以上時，才會保證下一年度不減薪。

## 22. 總結

網站現行薪資系統可以概括為：

1. 用能力值與所屬聯盟平均水準的差距產生 `d`。
2. 生涯年、低潮年及獎項改變薪資評價。
3. `p ≤ 7` 時薪資線性成長。
4. `p > 7` 後，一軍聯盟加入二次方明星加成。
5. 野手守位與合約類型會進一步放大或降低年薪。
6. 年薪在球季結束後重算，並於下一年度支付。
7. 升格及重要獎項提供不減薪保護。
8. 複數年合約目前仍可能逐年更新年薪，並非完全固定金額。
