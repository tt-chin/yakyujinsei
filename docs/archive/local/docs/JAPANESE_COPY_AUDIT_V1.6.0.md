# v1.6.0 表示文案監査結果

## 監査範囲

`docs/index.html`、`docs/src/config.js`、`docs/src/data/*.js`、`docs/src/engine/*.js`、`docs/src/ui/*.js`の画面、選択肢、カード、エラー、画像代替テキストを対象とした。内部enum、状態キー、エラーコード、コメントは表示されないため対象外とした。CPBLの球団名・地名に含まれる漢字は、正当な固有名詞として維持した。

## 修正した到達可能文案

- 契約種別の内部コードを共通ラベルで日本語化し、年度別年俸、保証額、支払済み、未払い保証額の表記を統一した。
- 契約画面の「年度schedule」、契約期間別内訳、契約種別係数、球団の需要度、市場評価値、守備位置係数を自然な用語へ統一した。
- 「ミート」「シーズン成績」「キャリアハイ」「失った特性」「イップス」「隠し特性」「球団の評価」「昇格通知」などへ統一した。
- 重傷、全休、深刻なスランプ、日本代表招集、契約延長、ポスティング、問題行動による契約非更新、進学・ドラフト再挑戦の到達可能文案を文脈に合わせて修正した。
- 引退画像の代替テキストを「引退リザルト画像」へ変更した。

## 未表示・未削除の旧文案

`docs/src/engine/game.js`は、後半の日本版オーバーレイが基礎関数を再代入する構成を維持している。以下は上書き前の到達不能ブロックにのみ残るため、仕様に従って削除・置換していない。

- 旧 `runDraft`：「ドラフトで負けた」などの旧ドラフト文案。
- 旧 `pathChoiceHS`：「新人聯盟」などの旧米国挑戦文案。
- 旧 `pathChoiceU4`：「裁判所に別れ」などの旧引退文案。
- `if(false)` で封印された旧大学シーズン前プロ挑戦ブロック。
- 旧契約市場関数内の「契約タイプ」等の旧表示。現行のFA・契約表示は後半のSchema v3処理と共通ラベルを使用する。

上記の旧処理は、到達性とRNG評価順を変えないため、v1.6.0では現状のまま保存する。
