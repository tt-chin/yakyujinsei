# 第三輪固定策略 r3-v1（執行前登錄）

基準18f9decb3a314beb9e70d74465fd1f6096f22d52、1.11.9。001–010 KBO-SP、011–020 KBO-Bullpen、021–030 USA-SP、031–040 USA-Bullpen。每批10条，逐條執行，批末第一個Seed完整重播；遊戲錯誤／未退休／資產失敗／重播或完整性不符即停止，不開下一批。首40外不得加Seed。

所有操作都是有效DOM click，不寫S或主RNG。以下規則在開始前固定；即使沒有目標樣本也不改。

- SP配分：sta未60且該行可配時先sta；其後在vel／ctl／brk可配行中選目前值最小者，並列順序vel→ctl→brk；三項無可配行時選sta。Bullpen配分：先三項最低值、相同並列順序；三項無可配時才sta。無可配能力則確定；骰子不重擲，不Undo/reset挑結果。這是合法能力點選擇，不保證SP/Bullpen實際起用。
- 投球強度固定「全力投球」，TJ固定選手術，不選注射。事件固定第一個可用選項（目前卡片bold先），不根據成敗改難度；代表出場按第一個非退休可用選項。只使用當前有效callback。
- 角色會議：SP選接受先發；Bullpen選留牛棚。出生sta／角色若已是SP不強制MR；其他角色自動轉換尊重引擎。
- 已在目標系統時優先「現在の球団に残留／権利を行使せず残留／宣言残留」，其次同目標有效契約；不為取樣返回NPB。USA目標系統包含MiLB、MLB。無合法留隊／合約選項時按後述fallback，完整保存離開理由。
- 在目標以外：KBO一軍有效契約／移籍選項優先於フューチャース；USA優先「米国プロ組織と契約する」與描述R/A1/A2/A3/MLB的赴美契約，不把初約R說成MLB。兩者均需明示契約／移籍／オファー等文字，不能匹配訓練事件中的地名。
- 然後配分確定／完了／次へ；再NPBドラフト／プロ志望／指名／入團／オファー受諾；再第一個非退休選項；只有其他可用選項皆不存在時接受正常退休。其餘並列按DOM順序。配分與角色／強度／TJ選項優先於一般進路。

所有可用選項、選中文字、能力／階層／角色、sta／prevD／lastD、契約摘要、主R次數與值保存。選項出現按操作觀測與去重選單兩種統計，不能當獨立邀請概率。四組不同Seed及策略，不是相同能力的隨機對照試驗。研究工具／策略定義SHA256隨批次保存。
