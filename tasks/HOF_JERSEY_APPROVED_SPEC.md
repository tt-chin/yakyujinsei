# 殿堂評價與背號履歷：已批准、待實作規格

日期：2026-11-08。來源：使用者於本對話的逐項決定與後續四點補充。本文件為設計決策正本。殿堂與比較政策四項已於feature/hof-evaluation-policy本機實作並取得Quick85／0；Full／CI／Preview仍未執行，詳細狀態以驗收紀錄為準。背號與永久欠番仍未實作，研究中的投手係數未修改。不將設計批准視為發布完成。

## 1. 各聯盟殿堂的成績範圍

對應HOF-BUCKET-DECISION-01。NPB、MLB、CPBL、KBO一律只計該聯盟一軍成績；二軍、育成、MiLB均不計入各聯盟一軍殿堂，但完整保留在生涯紀錄與階級顯示。MiLB不併入MLB。

依實際取得當時可靠的league／level判定，不能以退役所屬或目前球團回填歷史。舊資料無法可靠分階級時保留原件與未知狀態，不推測、不直接作一軍、不將整個混合bucket算入一軍。實作前盤點可靠來源及未知資料的顯示方式，缺乏證據時不得為提高評價補造數據。世界生涯綜合成就若日後設立須獨立設計，不混入各聯盟殿堂；本輪不新增此評價。

## 2. 榮譽歸屬、下限及加分明細

對應HOF-HONOR-POLICY-01。保留目前MVP／最優秀投手賞至少明星、部門獎至少主力的方向，不視為自動入選殿堂。畫面說明實際生效理由，例如「スター選手（MVP受賞による評価）」。同時達到分數與榮譽下限時，理由須對應實際判定，不能用文案假造待遇。

個人獎與球隊優勝歸實際取得當年的聯盟，不按退役所屬歸類；同一成就不得在多聯盟或同一聯盟重複加分。採可靠實得紀錄，不從模糊歷史字串或目前所屬推測歸屬。缺乏來源時保留紀錄但不補造歸屬與待遇。去重身分、舊資料辨識與各Consumer接線須在實作盤點中給出具體對照，不擴大Award Registry歷史身分。

球隊優勝、國際賽／國家隊榮譽與個人獎分開展示明細。國際賽及國家隊榮譽獨立展示，對各聯盟殿堂的分數貢獻為0，也不提高評價下限；不得為補足被移除的加分而改給其他聯盟。個人獎與球隊優勝其餘已批准權重不在本補充中另調。

**規則變更**：取消目前NPB國際賽加分／國際榮譽下限，及只採各聯盟一軍成績，均屬殿堂規則修改，不是純顯示整理。既有歷史榮譽與生涯成績不得刪除或改寫。

## 3. 投手平衡與評分顯示

HOF-PITCHER-BALANCE-01為RESEARCH_ONLY：先調查SP／MR／CL與指標，不採A／B／C假說、不調係數。此維持原投手公式的決定不豁免本文件已批准的階級篩選與國際榮譽歸屬變更。

HOF-DISPLAY-ROUND-01：繼續以未取整分數判定。畫面採足以表達判定的精度，門檻附近若顯示仍可能誤導，明示「未達門檻」（日文UI用自然日文「基準未達」）。不因顯示精度改變門檻、下限或入選規則。實際小數位數及顯示範圍先以現行畫面與邊界測試確認，不假設四捨五入後即達標。

HOF-VOTE-STORY-01取消／不實作，移出待辦；不因取消提案而刪除或概率化既有票選演出。

## 4. 背號及年度履歷

對應PLY-01。初次入團由系統給預設號碼，玩家可修改；轉隊優先沿用舊號，明確禁用時再提供可用號。允許同球團主動改號，履歷保存球團、年度、背號字串，並記錄生效年度；不把過去年度改號覆寫成目前號碼。

一般號碼為字串「0」「00」「1」至「99」，0與00不同，不以Number正規化。僅排除遊戲內有明確資料的禁用號碼，不建立完整隊友占用模擬、不虛構隊友號碼或現實禁號資料。

預設號碼採固定規則，不新增或消耗生涯RNG；不影響能力、收入、出場、成績或殿堂評分。具體固定選號順序、禁號資料來源、同年多次改號記錄及舊存檔的未知背號初始化方式，須在實作前提出確定方案；未批准前不任意指定號碼或補造歷史。取消選號／重繪不得產生改號紀錄或遊戲副作用。

## 5. 永久欠番：保留後續設計，不在本輪實作

對應PLY-02。未來僅依同球團的一軍年資、成績及榮譽設計，不以跨聯盟總成就直接授予。不設定猜測門檻，不接入判定、抽選、能力或其他效果，不增加RNG。先完成PLY-01；永久欠番維持DESIGN_DEFERRED / NOT_IMPLEMENTED，不宣告完成。

## 6. 修改前後比較與驗收界線

對應TEST-COMPARE-BASELINE-01；POLICY_APPROVED / TOOLING_NOT_VERIFIED。每個允許差異須有規則、資料來源、觸發條件與具體欄位／顯示路徑，不能以「新版不同」略過整個S、收入、成績或RNG比較。固定歷史基準與golden不為通過而替換。

- 背號：只允許新增／修改背號資料、年度履歷、必要UI與正式版號metadata；既有能力、收入、出場、成績、選擇流程的其他部分及RNG值／順序／消費數須相等。舊狀態新增欄位另行嚴格驗證，不能全域忽略。
- 殿堂：逐項列出一軍篩選、榮譽當年歸屬／去重、國際榮譽0貢獻造成的評分、評價下限／稱號、殿堂結果、理由與退休演出差異；能追溯到確實受影響的聯盟與來源。比對其餘狀態，既有能力、收入及已完成賽季成績不可連帶改變。
- 純顯示精度：僅顯示內容改變，未取整分數與判定結果嚴格不變。
- 第一個批准差異前保持嚴格一致，不因出現合法差異就自動放行後續全部不同。同版重播仍完整嚴格比較。未解釋差異為REGRESSION。
- 未授權新增RNG抽選。若殿堂分支改變導致既有演出抽選呼叫不同，須先定位與提出因果證據及相容方案，不自動列為允許差異或擅改票選規則。

以上是已批准的設計與比較政策；仍需實作盤點、限定及AGENTS影響分類要求的驗證，完成後才可勾選功能待辦。文件本身不觸發Quick／Full，不升版、不更新玩家履歷、不提交或發布。
