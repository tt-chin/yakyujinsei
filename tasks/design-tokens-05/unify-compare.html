配色統一比較（UI-DESIGN-TOKENS-05 探測）

來源： 方法：

現值＝目前各主題手調的 CSS 色彩值；統一後＝每個 token 採用一條 4 主題共用的 color-mix 規則，以 12 個基礎色＋新增 gold／highlight 共 14 色，加 white/black/transparent 為調色素材、暴力搜尋 p=1..99 整數比例，取對所有主題平均 OKLab ΔE 最小者，非人工設計。

注意事項
  • 數值以 Node.js 實作 CSS Color 4 規格計算，未經瀏覽器實測。
  • ΔE 為 OKLab 色差距離，計算時將色值疊合在各主題 --bg 上；約 0.02 為可察覺門檻，0.05 以上可能明顯可見。
  • Mock 元件為示意用途，不是遊戲實際畫面。
  • 部分現值 token（如陰影、overlay）使用半透明 RGBA；統一後公式為不透明色，視覺效果可能有顯著差異，請特別留意 overlay、shadow 相關 token。
