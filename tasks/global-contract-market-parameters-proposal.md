# 全球契約金・年俸市場：待確認參數提案

提案日期：2026-10-07。基準：dev v1.8.2。使用者已確認全部參數並批准實作（2026-10-08）。v1.9.0 實作正本移管至 CURRENT_SPEC.md §11；此文件保留承認時的原提案及驗證要求，不作為另一份現行正本。

本文件補齊 GLOBAL_SIGNING_BONUS_SYSTEM_FIX.md 與 GLOBAL_SALARY_MARKET_SYSTEM_FIX.md 的未定參數。不是 CURRENT_SPEC 的已實作內容，也不是新版本履歷。

## 1. 已確認的決定

- CPBL 一般漲幅上限為原年俸的 2.5 倍，明星例外為 4 倍。900 萬円案例的一般上限為 2250 萬円，修正原文的 2500 萬円範例。
- 評價只作為既有 salaryFor(targetLevel, convertedRating) 的輸入，不再直接乘一次評價。
- 外國職業選手豁免必須同時滿 25 歲及 6 季認可一軍年資。
- 育成支度金使用獨立欄位，signingBonus = 0，但計入生涯收入。
- 採用 NPB 更新時的減額保護：前年俸不超過 1 億円保留 75%，超過 1 億円保留 60%。不套用於自願跨聯盟轉隊，也不溯及減少已簽固定契約。
- 新價格的預期差異及直接收入差異可以存在；不得新增 RNG 消費或更改呼叫順序。
- 同一契約重複處理、重繪、正規化不得重複付款。不新增生涯保存／讀取功能。

以下數值全部是「待確認的遊戲政策」，除明確標示的制度參考外，不宣稱是現實制度或即時匯率。

## 2. 共通定義及計算順序

- 金額內部使用円。下列金額以萬円表示。
- 評價、par 換算、近三季權重、守位、傷病、契約種類、球團需求、競爭、franchise 與 bid jitter 使用現行函式；每個倍率只套用一次。
- 基準年俸 P：候選生成前的移籍前有效合約年俸，先保存快照，不能在 buyout 清除 currentSalary 後重算。沒有有效額時依保存的最近年度合約／薪資決策取值；不得把簽約金、買斷金或獎金加進 P。無可靠正額則停用 anchor 與相對漲幅限制並註記原因。
- 目標市場 M：現行目標階層曲線乘既有市場倍率。
- 路線調整 T = M × 路線倍率。
- 混合 A = P × (1 − weight) + T × weight。
- 跨聯盟預設不保障最低漲幅，也不套用移籍前聯盟的減薪保護；maxCutRate 定義為最多可減少比例，預設 1（最多減少 100%，仍受目標階層最低額保護）。minRaiseRate = 0 不表示禁止降薪。
- 先套用相對漲幅上限，再套用目標階層最低額，最後套用目標市場／合約總額上限。最低額可優先於相對漲幅上限，須顯示理由。
- 若最低額與硬性合約上限衝突，不刪減候選或悄悄違反制度，回報政策衝突；不得因此更動候選數或抽選。
- 最後以 1 萬円四捨五入，若會突破硬性上限則向下取至 1 萬円；再驗證 floor 及 package。候選保存確定額，受諾直接沿用。
- 已簽約的 annualSchedule、延長、交易承接及買斷基準不重算。

## 3. 評價分級

- 一般：不滿足明星條件。
- 明星：OVR ≥ 60、現行 marketRating ≥ 3，且最近三季有至少兩季一軍有效薪資評價 payD ≥ 3、sampleStatus 非 INSUFFICIENT。
- 超級：OVR ≥ 65、marketRating ≥ 6，且最近三季有至少兩季一軍有效 payD ≥ 6。
- 不用目前能力反推歷史成績。資料不足不給例外；一軍升格當季的 OVR54 選手不屬於明星。
- 本分級只用於新增跨聯盟價格政策，不替換既有 injury-market 的 isRecentStar，也不更改 FA 候選數或資格。

## 4. 新人契約金

NPB 維持原有一次 ri()，單位萬円、含上下界：

- 1 巡：8000～10000。
- 2 巡：5000～7500。
- 3 巡：3500～5500。
- 4 巡：2500～4500。
- 5 巡：2000～3500。
- 6 巡：1500～3000。
- 育成：契約金 0、developmentStipend 290。原有契約金抽選仍在原位置消費一次，但不以抽選結果決定支度金。

美國國際業餘契約依候選生成時 OVR 確定，沒有額外 RNG：

- OVR < 50：300～1000；以 OVR40～50 線性插值，低於40取300。
- 50 ≤ OVR < 60：1000～3000；依50～60插值。
- 60 ≤ OVR < 70：3000～8000；依60～70插值。
- OVR ≥ 70：8000～20000；依70～80插值，高於80取20000。
- 以上是個人遊戲契約金上限2億円，不建立或聲稱完整模擬球團實際 bonus pool。
- 高中、大學初次 MiLB 簽約及首次美國受限路線使用相同公式；續約、延長、MLB/MiLB 系統內升格不重新領契約金。
- 一般 KBO／CPBL／NPB 復歸及豁免職業 FA 新簽契約金預設0；不額外創造 FA bonus 或支度金。

## 5. 跨聯盟路線參數

以下每條順序為「倍率；weight；一般／明星最大年俸倍數」。超級在明列例外以外沿用明星上限。

### 目標 CPBL

- NPB → CPBL：1.00；0.60；2.5／4.0。
- KBO → CPBL：0.95；0.60；2.0／3.0。
- MLB → CPBL：1.00；0.70；1.5／2.0。
- MiLB → CPBL：1.00；0.70；2.5／4.0。
- 所有來源的 CPBL1 新簽市場硬上限：一般8000、明星10000；CPBL2 上限1200。
- CPBL1／CPBL2 最低額沿用現行1200／400，不另作台幣月薪與全年薪資混算。

### 目標 KBO

- NPB → KBO：1.00；0.65；3.0／4.0。
- CPBL → KBO：1.00；0.65；3.0／4.0。
- MLB → KBO：1.00；0.70；1.5／2.0。
- MiLB → KBO：1.00；0.70；3.0／4.0。
- KBO1／KBO2 最低額沿用現行4000／800；KBO2 年俸市場上限3000。
- 另受第6節 package 上限約束。

### 目標 NPB

- KBO → NPB：1.00；0.70；2.0／4.0。
- CPBL → NPB：1.00；0.65；3.0／5.0。
- MLB → NPB：1.00；0.70；無相對漲幅上限，但將混合用的 P 限制至 T 的1.5倍，避免舊MLB高薪支配報價。
- MiLB → NPB：1.00；0.70；2.5／4.0。
- NPB1／NPB2／育成最低額沿用現行1600／500／300；新簽市場硬上限60000／1600／500。
- 日本人玩家返回 NPB 不套用「外國人補強 premium」。不新增國籍或外國人補強系統。

### 目標美國

- NPB／KBO／CPBL → MLB 的豁免一般職業路線：1.00；0.95；6.0／無上限（後者須超級，而非僅明星）。仍受現行曲線及市場倍率計算，不保證天價。
- 真正 MLB FA（現行 MLB serviceTime ≥ 6）的合約市場不使用跨聯盟 anchor 或相對漲幅上限，保持現行市場基礎。
- NPB／KBO／CPBL → MiLB：1.00；0.80；一般／明星均無相對漲幅上限，但嚴格區分 R／A1／A2／A3；新簽硬上限300／400／600／3000，最低額300／400／600／1000。
- MLB ↔ MiLB 是同一美國系統的階層移動，不當成初次國際簽約，不重新發 bonus，升降格使用既有合約規則。
- 初次美國簽約不滿豁免資格：採國際受限契約金；若既有候選目標是 MLB，改為同一球團的 R 國際業餘契約，年俸300、之後升格仍走現行流程。既有球團抽選、候選位置／數量及年數抽選不變。此項會有預期的階層及後續生涯差異，需明確批准。
- 已在 MLB/MiLB 系統的選手不因年齡／海外年資再次退回國際業餘路線。

### 特殊與預設

- 戰力外後跨聯盟：沿用來源／目標倍率與weight，但一般漲幅上限1.5、明星2.0覆蓋一般路線；目標最低額及package限制仍優先。真正 MLB FA 豁免例外不套用於戰力外證明契約。
- 同年再次轉隊：沿用該次轉隊前合約快照，不把已清除的0當作基準。
- 同聯盟 FA、續約、升降格：不套用上述跨聯盟表；只有已批准的 NPB 減額規則及 KBO package 限制需處理。
- 未明列的非職業來源初次合約不套用前薪 anchor；保留既有可選路線及目標階層，不新建海外候選。
- 未知職業聯盟／階層不能套用虛構fallback；須在測試中報告缺失。

## 6. KBO 總額上限及匯率

- 固定遊戲換算：1 USD = 150 JPY。不按遊戲年度或即時匯率浮動；不再為既有円金額重複換匯。
- 本次既有 KBO 海外路線明確分類為 FOREIGN_STANDARD，不因日本國籍自動改成亞洲名額。亞洲名額不在這次新增，待獨立路線／球團名額規格確認。
- 新加入一般外國人：單年 package 上限15000萬円（100萬美元參考）。年俸、契約金、最大可領option及任何此路線球團移籍費都納入成本；球團費用仍非選手收入。
- 續約上限採遊戲用個人政策：max(15000, 前一約單年package × 1.20)，最高30000萬円。不是聲稱KBO現實個人法定上限；不模擬其他外國選手或全隊400萬美元預算。
- 7%出來高公式維持。先扣除固定契約金與球團移籍成本，再求能容納年俸及其7%最大出来高的最高年俸。萬元捨入後重驗；不得先領錢再扣回。
- 新簽與續約候選提前確定最終額及出来高；已簽年表不溯及削減。多年度約逐年度驗證，不改抽出的合約年數。
- 制度參考：KBO https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=8542 （新人100萬美元及球團總額規則）；https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=11879 （亞洲名額另列）。

## 7. 一軍年資及 posting

- 豁免年資只加總 NPB1、KBO1、CPBL1。在同一年最多計1季，且當年一軍 seasonFactor ≥ 0.5；全休、二軍、育成、MiLB、獨立、社會人皆不計。
- 另記認可一軍季數，不替換現行保有權／FA serviceTime。不從混合一二軍的league stats.yr補算。
- 舊狀態缺少新年資時，僅從保存的年度階層與稼働資訊重建；證據不足不猜測豁免資格，標示資料不足。既有MLB/MiLB選手不重跑首次資格判定。
- 既有 NPB 非海外FA的赴美轉隊分類為遊戲簡化 posting，無需新增球團同意抽選；已有海外FA權或戰力外則fee=0。不將所有海外轉隊誤標為posting。
- Major posting：以保證年俸總額及保證契約金作為保證成本 G；前2500萬美元20%、接著2500萬美元17.5%、超過部分15%，依固定150匯率計円金額。未保證出来高不納入初期fee。
- Minor posting：契約金25%。育成支度金不算美國國際契約金。
- 本次只處理 NPB → 美國的posting；KBO/CPBL不自行虛構posting資格或球團fee。
- 收款者為移籍前NPB球團ID。fee記錄在合約，但不加入careerEarnings、careerSigningBonus、careerBaseSalary或買斷保障。
- 不新增option達成後追加posting fee，也不建立球團財務系統。
- 制度參考：https://www.mlb.com/glossary/transactions/japanese-posting-system 。

## 8. 一次性付款及舊狀態

- signingBonus、developmentStipend、postingFee 分欄，schemaVersion仍為3；signingBonusType只分類signingBonus，育成契約另以支度金欄位及其來源說明。
- applySigningPayment以contractId記錄已領契約金／支度金，兩筆收入在同一接受動作中一次完成；再呼叫、重繪、normalize均不再付款。
- 育成支度金另計careerDevelopmentStipend，收入內訳各自顯示。選手總收入只加一次；舊careerSigningBonus保持原累計，不回溯分拆。
- 缺欄位補0；舊signingBonus>0且無type補LEGACY。舊契約正規化不觸發付款；過去累計不重算，新付款紀錄不得把舊bonus誤當未領新款。
- 拒絕合約無入帳；轉隊承接、延長、升降格不重領。
